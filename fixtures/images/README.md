# Картинки для тестов

Картинки аннотаций-изображений для эталонов `crates/ops/tests/golden/image.rs`. Сделаны FFmpeg из `.deps`:

- `sticker.png` — 160×100 RGBA: круг с градиентом, полупрозрачная полоса сверху, остальное прозрачно (`color=c=black@0` + `geq`).
- `blink.gif` — 120×90, 3 кадра по 200 мс с номером кадра (`testsrc2=s=120x90:r=5:d=0.6`).
