# Фикстуры записи v2 (задача 3.16)

Настоящие записи DevCast v2 для тестов этапов 4–5: события кликов, автозумы, показ клавиш, звук, курсор. Каждая — готовый проект `<имя>.devcast`, как его создаёт `devcast record`: `project.json` (один клип с настройками по умолчанию) и папка записи `media/recording-1/` — `video.mp4`, `system.mp4` (системный звук, FLAC), `manifest.json`, `cursor.bin`, `keys.bin`, `cursor-NNNN.png`. Видео, PNG и `.bin` лежат в Git LFS (`.gitattributes`).

Всё, кроме речи, пишет скрипт на мониторе `DEVCAST_TEST_MONITOR`: своё белое окно 1280×720 по центру монитора (поверх остальных), источник — область ровно по окну, 60 fps, системный звук включён. Окно рисует набранный текст и чёрный квадрат 12×12 в месте каждого клика: так кадр сверяется с событием в `cursor.bin`. Над левой половиной окна курсор — стрелка, над правой — рука. Каждая запись начинается и кончается секундой без действий. Координаты в `cursor.bin` — пиксели видео от левого верхнего угла.

## Перезаписать

Скрипт забирает мышь и клавиатуру примерно на минуту и играет тоны — только когда за компьютером никто не работает. Существующая фикстура с тем же именем заменяется.

```
DEVCAST_TEST_MONITOR=2 cargo run -p dc-capture --example record_fixtures
DEVCAST_TEST_MONITOR=2 cargo run -p dc-capture --example record_fixtures -- clicks typing
```

После записи посмотреть кадры (например, `ffmpeg -ss 3 -i fixtures/recordings/clicks.devcast/media/recording-1/video.mp4 -frames:v 1 clicks.png`) и закоммитить папку: файлы `lock` и `lock-owner.json` проекта в git не попадают (`.gitignore`).

## Речь в микрофон (владельцу)

Одна команда из корня репозитория; имя микрофона и угол монитора 2 — из `devcast ls sources` (строки `--mic "…"` и `screen:2 … в X,Y`):

```
cargo run -q -p dc-cli --bin devcast -- record --source area:X,Y,1280,720 --mic "Микрофон (…)" --duration 15 -o fixtures/recordings/speech.devcast
```

Говорить 15 с обычным голосом по-русски, с паузами 1–2 с между фразами (для поиска тишины и субтитров). В проекте будут дорожки `system` и `mic`.
