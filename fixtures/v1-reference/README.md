# Эталоны v1 (задача 0.16)

Эталон **стиля**, а не пиксельного совпадения. По этим роликам агент на этапе 5 сверяет, что зумы, курсор, клики, аннотации и субтитры v2 выглядят не хуже v1.

## Что сделать (владельцу, в приложении v1)

Для каждого сценария ниже:
1. Записать ролик в v1.
2. Настроить, как описано.
3. Экспортировать **MP4 1080p, 60 fps, качество высокое**.
4. Положить в папку `fixtures/v1-reference/<номер>-<имя>/` два файла: `export.mp4` и файл проекта `.devcast`.

Кадры из роликов агент достанет сам.

### 1-zoom — зумы

- Запись 20–30 с. Три клика в разных углах экрана, между кликами пауза 2–3 с.
- Включить автозумы. Дополнительно поставить один ручной зум в режиме слежения за курсором и подвигать курсор внутри него.
- Пресет движения — Smooth.

### 2-cursor — курсор, клики, облачко

- Запись 20 с:
  - быстрые и медленные движения;
  - 5–6 кликов, один из них двойной;
  - перетаскивание окна;
  - курсор над текстом (I-beam) и над ссылкой (рука).
- Курсор: набор macOS, сглаживание включено, motion blur включён, bounce по умолчанию.
- Эффект клика Ripple. Один клик — «подсветка клика» с частицами.
- Облачко у курсора: включить на 3-й секунде, сменить текст на 8-й, выключить на 14-й.

### 3-annotations — аннотации

- Любая запись на 20 с. На ней:
  - текст на русском с плашкой, анимация typewriter;
  - стрелка с градиентом из 3 цветов и свечением, анимация draw-in;
  - прямоугольник с обводкой, анимация fade;
  - эллипс с анимацией pop;
  - рисунок кистью;
  - размытие области с тонировкой;
  - картинка со slide слева.
- У одной аннотации два ключевых кадра: она переезжает через полэкрана.

### 4-captions — субтитры

- 20–30 с русской речи в микрофон (можно рассказать, что происходит на экране).
- Сгенерировать субтитры (Whisper small, язык auto). Стиль по умолчанию, подсветка слова включена, анимация pop.

### 5-audio — звук

- Запись 30 с: на фоне играет системный звук (видео или музыка), параллельно говорите в микрофон.
- Добавить дополнительную аудиодорожку (любая музыка).
- Микрофон: усиление ×2. Системный звук: 50%.
