# Звук для тестов

| Файл | Что в нём | Как сделан |
|---|---|---|
| `tts-ru.flac` | Чистая русская речь без шума, 48 кГц моно, ~10 с: «Привет. Сегодня я покажу, как записать видео с экрана и вырезать паузы. Это занимает пару минут.» | Синтезатор Windows (голос Microsoft Irina Desktop, `System.Speech`), затем `ffmpeg -ar 48000 -ac 1 -c:a flac` |

Шум к речи тесты подмешивают сами (`anoisesrc` FFmpeg), чтобы знать, где речь, а где шум.
