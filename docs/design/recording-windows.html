Переключатель в блоке кнопок: «Свободно» / «16:9» (тянется с сохранением пропорции) / «1080p» (рамка ровно 1920 × 1080 физ. px, только двигается; неактивен, если монитор меньше). Подпись размера дописывает пропорцию.
