# Эффекты клика и облачко курсора: выжимка из v1 (задача 0.11)

Агент, который делает эффекты клика и облачко в v2, читает только этот файл и `cursor.md` (обозначения, позиция и сглаживание курсора). Код v1 открывать не нужно. Ссылки `файл:строка` даны относительно `.v1/src/`. Метки: **v1** — как сделано; **Рек.** — предложение для v2, а не факт v1; **не переносить** — баг или костыль v1 (причина рядом).

## 0. Обозначения

- `t` — время исходника, мс. Исключение — события облачка в v1, см. §12.
- `W` — ширина контента клипа в кадре до камеры, px. ref-px — пиксель при `W = 1920`.
- `h = 28 · size · W/1920` — базовая высота курсора. `H = h · k_style` — высота картинки без bounce. `k_style`: macOS 1.716784, Windows 11 1.678689, своя картинка 1; в v1 по умолчанию стоял Tahoe с `k_style = 1` (`cursor.md` §7, §8.3).
- Эффекты и облачко лежат в слое курсора внутри контейнера камеры, поэтому масштабируются зумом. Порядок слоёв снизу вверх: эффект клика, тень, курсор, плашка облачка, текст облачка (`components/video-editor/videoPlayback/cursorRenderer.ts:1263-1271`).
- Все кольца — обводка по центру линии без заливки, если не сказано иное. Цвет задан hex, альфа отдельно.

## 1. Какие события считаются кликом и когда идёт эффект (v1)

- Клик — сэмпл с `interactionType ∈ {click, double-click, right-click, middle-click}`. `mouseup` игнорируется (`cursorRenderer.ts:810-828`).
- В расчёт берётся **только последний** клик с `t_click ≤ t`.
- Тайминг (`cursorRenderer.ts:1042-1076`):
```
age   = t − t_click
delay = Db · 0.5           // Db — длительность bounce курсора, 60–500 мс, по умолчанию 350
ea    = age − delay
p     = (0 ≤ ea ≤ De) ? 1 − ea/De : 0      // De — длительность эффекта, 120–1200 мс, по умолчанию 600
if style == none or p <= 0: ничего не рисовать
u     = 1 − p              // прогресс 0 → 1; формулы ниже даны и через p, и через u
```
- Эффект стартует в середине bounce, когда курсор сильнее всего сжат. Задержка зависит от `Db`, даже если сам bounce = 0.
- Позиция — **сырая** точка клика (`cx`, `cy` сэмпла клика), спроецированная в кроп (`cursorRenderer.ts:1454-1470`). За курсором эффект не едет. При включённом сглаживании курсор может отставать от кольца.
- Если точка клика вне кропа, эффект не рисуется.
- Эффект рисуется и при выключенном «Показать курсор».
- Размер считается от `H` без bounce (`cursorRenderer.ts:1534-1547`).
- **Граничные случаи v1:**
  - новый клик мгновенно убирает старый эффект, а новый появляется только через `Db/2`, поэтому между ними видна пауза;
  - двойной клик даёт два запуска: первый `mousedown` пишется как `click`, второй как `double-click`;
  - правый и средний клик тоже дают эффект.
- **Рек.:** в v2 рисовать все клики, у которых эффект ещё активен (наложение), а не только последний. Это нужно и для настройки отдельного клика (§9).

## 3. Общие величины (`cursorRenderer.ts:928-932`)

```
alpha = p · opacity                  // линейное затухание от opacity до 0
base  = max(12, 0.55 · H · scale)    // px
sw    = max(2, 0.08 · H)             // px, от scale НЕ зависит
```

## 4. Ripple (`cursorRenderer.ts:896-910, 934-944`)

Одно кольцо, хотя описание в UI говорит о «кольцах»:
```
eased = 1 − p³        // = easeOutCubic(u)
fade  = p³            // = (1 − u)³
r     = max(0.5, eased · H · 1.95 · scale)
stroke: width = max(1, 2 · fade) px; alpha = clamp(fade · 0.6 · opacity, 0, 1)
```
Не использует `base` и `sw`. Кольцо растёт из точки и быстро гаснет, к концу его толщина 1 px.

## 5. Spotlight (`cursorRenderer.ts:946-954`)

Два кольца растут линейно по `u`:
```
R1 = base + u · H · scale
R2 = max(0.72 · base, 0.76 · R1)
кольцо R1: width = max(1.25, 0.68 · sw), alpha = 0.28 · alpha
кольцо R2: width = max(1.5,  0.75 · sw), alpha = 0.50 · alpha
```
При `u = 0` оба кольца сразу видны с радиусом около `base`, затем расходятся и гаснут.

## 6. Echo (`cursorRenderer.ts:956-963`)

```
R1 = base + u · H · 1.22 · scale
R2 = max(0.58 · base, 0.62 · R1)
кольцо R1: width = sw,                 alpha = 0.72 · alpha
кольцо R2: width = max(1.4, 0.72 · sw), alpha = 0.42 · alpha
диск в центре: radius = max(3, 0.18 · base), заливка, alpha = 0.14 · alpha
```

**Числа для проверки.** 1080p, `W = 1920`, size 2.5, `scale = 1`, `u = 1`.

## 7. «Вспышка с частицами» — бывшая аннотация «Подсветка клика»

### 7.1. v1: аннотация типа `click`
- Отдельный регион на дорожке аннотаций с прямоугольником (позиция и размер в процентах от видео).
- Эффект рисуется в центре прямоугольника, пока `start ≤ t ≤ end` региона, с анимациями входа и выхода аннотации.
- Время — время таймлайна.
- Данные (`types.ts:511-516, 579-584`; clamp — `projectPersistence.ts:731-750`):
  - `color` — `#60A5FA`;
  - `particleCount` — 18, UI 0–60, шаг 1;
  - `radius` — 90 ref-px, UI 20–300, шаг 1, подпись «px»;
  - `durationMs` — 750, при загрузке clamp 100–5000, в UI нет.
- UI: «Цвет круга», «Частицы», «Размер» с подсказкой «A timed highlight: particles expand slightly, stop, then fade out.» (`components/video-editor/AnnotationSettingsPanel.tsx:1301-1370`).

Отрисовка, экспорт (`lib/exporter/annotationRenderer.ts:402-459`):
```
u = min(1, max(0, t − start) / max(1, durationMs)); if u <= 0: ничего
fade   = (1 − u)^1.35
expand = 1 − (1 − u)³                       // easeOutCubic
S = max(0.01, W/1920) · camScale            // px на ref-px, с учётом зума (annotationRenderer.ts:18-20, 661)
Rt = min(radius · S, 0.48 · min(boxW, boxH)) // целевой радиус, ограничен боксом аннотации
r  = Rt · expand
// 1) мягкий диск без контура:
disk(center, r), радиальный градиент от центра к r:
    0% → color @ 0.62;  42% → color @ 0.20;  100% → color @ 0;   весь диск × fade
// 2) частицы — спираль Фогеля («подсолнух»):
for i in 0..N−1:
    angle = i · 2.399963229728653                         // золотой угол, рад (≈137.508°)
    dist  = Rt · sqrt((i + 0.5)/max(1, N)) · (0.82 + 0.18 · expand)
    rad   = max(1, Rt · (0.018 + 0.005 · (i mod 4))) · expand
    круг (center + (cos angle, sin angle) · dist, rad), сплошной color, alpha = fade
```
- Частицы равномерно заполняют диск и почти не разлетаются: расстояние растёт с `0.82` до `1.0` от финального. Радиусы частиц идут циклом из 4 размеров: 1.8 %, 2.3 %, 2.8 %, 3.3 % от `Rt`.
- Диск и частицы растут из нуля и плавно гаснут. Changelog: «мягкая вспышка без жёсткой рамки: растёт из нуля, частицы распределяются внутри области и плавно затухают» (`config/Changelog.md:124`).

Превью отличается от экспорта (`components/video-editor/AnnotationOverlay.tsx:602-656`):
- (а) у диска есть свечение — CSS `drop-shadow(0 0 max(2, 0.26·r)px color)`;
- (б) прозрачность частицы `fade · (0.5 + 0.1 · (i mod 4))`, то есть 0.5, 0.6, 0.7, 0.8;
- (в) при `u = 0` вся SVG имеет `opacity 0`.

**Не переносить:**
- Превью и экспорт расходятся.
- В экспорте `ctx.globalAlpha = fade` для частиц затирает альфу анимации входа и выхода (`annotationRenderer.ts:442`).

### 7.2. Рек. для v2: стиль эффекта клика «Вспышка с частицами»

Нужно согласие владельца.
- Центр — точка клика, тайминг и `p`/`u` — §1 (с той же задержкой `Db/2`). Замена: `u = 1 − p`.
- Цвет — общий цвет эффекта, значит по умолчанию `#2563EB`, а не `#60A5FA`. Длительность — общая, 600 мс вместо 750.
- `Rt = 90 · (W/1920) · scale` — от размера курсора не зависит, как у аннотации. Ограничения `0.48 · бокс` нет. Зум добавится сам через камеру.
- Прозрачность: `fade · opacity`.
- `N = 18` фиксированно, в SCOPE нет настройки числа частиц.
- Брать вид превью: свечение `max(2, 0.26·r)` и альфы частиц 0.5–0.8. Его пользователь видел при монтаже.

## 9. Проблемы v1 и новое в v2

- **Не переносить, абсолютные px.** Минимумы 12, 2, 1.25, 1.5, 1.4, 3 px и толщина ripple 1–2 px не масштабируются с `W`. На 4K ripple превращается в волосок, а превью (CSS-px) расходится с экспортом. **Рек.:** все такие числа считать в ref-px, то есть умножать на `W/1920`.
- **Не переносить, размер от `k_style`.** Эффекты считаются от `H = h·k_style`, поэтому смена набора меняет размер эффектов. Привычный вид v1 подобран на Tahoe с `k = 1`, а на macOS и Windows эффекты в 1.7 раза крупнее. Открытый вопрос 1.
- **Не переносить, blur.** Motion blur курсора висит на всём контейнере и смазывает неподвижные кольца (`cursorRenderer.ts:1295`).
- **Не переносить, дубли.** Формулы продублированы для Pixi и Canvas2D (`cursorRenderer.ts:912-964` и `966-1040`). В v2 рендер один.
- **Новое в v2, в v1 этого нет.** По SCOPE отдельный клик на таймлайне можно отключить или перенастроить. **Рек.:** хранить для каждого события клика `{enabled, style?, color?, scale?, opacity?, durationMs?}`, а пустые поля брать из общих настроек.

## 11. Облачко: раскладка и стиль (`cursorRenderer.ts:1466, 1625, 1635-1685`)

```
visible = enabled and text.trim() != "" and точка курсора внутри кропа   // от «Показать курсор» НЕ зависит
(px, py) = сглаженная позиция курсора, если курсор рисуется; иначе сырая интерполированная
fs   = max(16, 0.72 · H · scale)                // px; H без bounce
padX = max(10, 0.55 · fs);  padY = max(7, 0.32 · fs)
текст: шрифт "Arial, sans-serif", weight 600, size fs, цвет textColor, без переноса
       (tw, th) — размеры текста по метрикам шрифта (Pixi Text)
w = tw + 2·padX;  hb = th + 2·padY
x = px + 0.60·H;  y = py + 0.54·H              // левый верхний угол пузыря, вправо-вниз от хотспота
roundRect(x, y, w, hb, radius = hb/2)          // «пилюля»
текст в точке (x + padX, y + padY)
```

- **Стиль:**
```
colors = (gradientEnabled and len(gradientColors) ≥ 2) ? gradientColors : [background]
n   = len(colors)
rot = floor(max(0, t)/2400 · n) mod n          // t — время курсора (исходника), мс
cyc = colors[rot:] + colors[:rot]
заливка: n > 1 → линейный градиент слева направо по боксу пузыря (Pixi FillGradient start (0, 0.5) → end (1, 0.5)),
                 стопы offset_i = i/(n−1) → cyc[i]; alpha 0.96
         n = 1 → сплошной cyc[0], alpha 0.96
свечение: только если gradientEnabled and glow > 0 — обводка того же roundRect,
          width = 0.42·glow px, цвет cyc[0], alpha 0.22, без размытия
```
- **Анимация градиента** — дискретный циклический сдвиг цветов раз в `2400/n` мс. Цвета перескакивают, а не плывут; полный цикл 2400 мс.
- «Свечение» в v1 — просто полупрозрачная обводка: половина ширины снаружи, до 8.4 px при `glow = 40`. У фигур v1 свечение настоящее: `shadowBlur = glow · k · 1.5` цветом градиента (`lib/exporter/annotationRenderer.ts:187-188, 282-286`). **Рек.:** анимацию и свечение облачка сделать той же реализацией, что у градиентов аннотаций (выжимка 0.12), а не переносить дискретный сдвиг и обводку. Открытый вопрос 3.
- **Края кадра в v1 не обрабатываются.** Пузырь всегда справа-снизу. У правого и нижнего края он выходит за кадр; маской видео он не обрезается, обрезает только холст. **Рек.:** проверять пузырь в итоговых координатах кадра, после камеры. Если `x + w > правый край − margin`, ставить слева: `x = px − 0.60·H − w`. Если `y + hb > нижний край − margin`, ставить сверху: `y = py − 0.54·H − hb`. Если не влезает и так — прижать к кадру. `margin = 16` ref-px. Нужно согласие владельца.
- **Прочее:**
  - пузырь не поворачивается sway и не сжимается bounce, но едет со сглаживанием и смазывается blur курсора (`cursor.md` §11);
  - многострочный текст (перевод строки из поля события) Pixi рисует в несколько строк, и радиус `hb/2` выглядит плохо. **Рек.:** одна строка, `\n` заменять пробелом;
  - **не переносить** минимумы в абсолютных px (16, 10, 7, ширина обводки): считать в ref-px.
- **Числа для проверки.** 1080p, size 2.5, `scale = 1`.
  - Tahoe, `H = 70`: `fs = 50.4`, `padX = 27.7`, `padY = 16.1`, смещение `(42, 37.8)`.
  - Windows 11, `H = 117.5`: `fs = 84.6`, смещение `(70.5, 63.5)`. Облачко в 1.7 раза крупнее привычного (открытый вопрос 1).

## 12. События облачка и печать текста

**Данные (v1).** Регион аннотации `type = "cursor-callout"`, контента не рисует:
- `startMs`, `endMs`;
- `calloutEvent.action ∈ {enable, text, disable}`;
- `content` — текст для `text`, до 80 символов;
- `calloutEvent.style?` — частичный `{background, textColor, scale, gradientEnabled, gradientColors, gradientGlow}`.

Ссылки: `types.ts:518-537`; clamp — `projectPersistence.ts:751-762`.
- Новое событие получает `action = "enable"` (`components/video-editor/hooks/useAnnotationRegionCommands.ts:143-146`). При переключении на `text` с пустым текстом `content = "Text"` (`useAnnotationRegionCommands.ts:243-256`).
- Длительность нового региона — `min(1000 мс, длительность таймлайна)` (`components/video-editor/timeline/hooks/actions/useTimelineZoomActions.ts:40`).
- Подписи на таймлайне: «Callout on», «Callout off», «Callout: <текст или Text>» (`components/video-editor/timeline/model/timelineModel.ts:38-41`).
- **Длительность события — это длительность печати или стирания.** Подсказка UI: «Длительность события задаёт анимацию печати.»

**Резолвер** (`types.ts:539-577`) без состояния: каждый кадр всё считается заново, поэтому превью и экспорт совпадают.
```
fn resolve(events, t, g):                       // g — глобальные настройки §10
  st = {enabled: g.enabled, text: g.text, style: {}}
  for e in events where e.start ≤ t, sorted by (start, id):
    if e.style: st.style = {...st.style, ...e.style}  // стиль копится всегда, даже у игнорируемых событий
    act = e.action ?? "text"
    D = max(1, e.end − e.start); q = clamp((t − e.start)/D, 0, 1)
    if act == enable:
        st.enabled = true; st.text = g.text      // сразу, без печати; длительность не важна
    elif act == text and st.enabled:
        target = (e.content.trim() || g.text.trim() || "Text")[0..80]
        if q > 0:  st.text = target[0 .. max(1, round(len(target)·q))]
        if q >= 1: st.text = target
        // q == 0 (ровно t == start): остаётся прежний текст
    elif act == disable and st.enabled:
        st.text = st.text[0 .. round(len(st.text)·(1 − q))]   // стирание с конца
        if q >= 1: st.enabled = false; st.text = ""

```

**Поведение:**
- Печать равномерная: `len/D` символов в мс. Первый символ появляется сразу после `start`.
- **Смена текста.** Старая надпись держится до начала нового события. С первого же кадра после `start` она целиком заменяется первым символом нового текста; старый текст не стирается. Так пустой кадр не мигает (`config/Changelog.md:50`).
- `disable` стирает текст с конца за `D`. Когда остаётся пустая строка, облачко пропадает чуть раньше конца события.
- Если `text`-события перекрываются, побеждает то, что началось позже.
- Если глобально облачко включено, оно видно с 0 с глобальным текстом и без событий.
- После `enable` при пустом глобальном тексте облачко включено, но не видно до первого `text`. Changelog говорит «появляется после включения даже без события текста» (`config/Changelog.md:85`); это верно, только если глобальный текст не пуст.
- Стиль события действует с его `start` до конца ролика или до следующего события, задающего то же поле.
- UI события (`components/video-editor/AnnotationSettingsPanel.tsx:417-457`): выбор «Включить», «Текст», «Отключить»; поле текста только для «Текст»; блок «Стиль подписи» с фоном, цветом текста, размером 50–200 %, градиентом (2–4 цвета) и свечением 0–40. Пустые поля показываются как `#14B8C4` и `#FFFFFF`, но в рендере берётся глобальная настройка.

**Время событий.**
- v1 считала события по времени таймлайна, то есть выхода (`components/video-editor/VideoPlayback.tsx:2249-2258`, `lib/exporter/modernFrameRenderer.ts:2988-2998`; Changelog:129). Сдвиг цветов градиента при этом шёл по времени исходника.
- По ARCHITECTURE.md v2 всё привязано ко времени исходника. Тогда на ускоренном участке печать тоже ускорится (открытый вопрос 2).

**Не переносить:**
- Режут строку по UTF-16 (JS `slice`), поэтому эмодзи и суррогаты могут разорваться. **Рек.:** резать по графемам.
- В резолвере действие по умолчанию — `text`, а при создании — `enable`. В v2 действие обязательно.
- События облачка в v1 проходили через ключевые кадры аннотаций. В v2 ключевых кадров у них нет.
