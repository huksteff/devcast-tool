## Правила, которые владелец повторял

- Коммит на задачу: `add:`/`chg:`/`fix:`/`del:`, по-английски, без упоминания Claude и без `Co-Authored-By`. Никогда не пушить. `git commit --only <пути>`, никогда `git add -A`.
- Одна сборка за раз. `CARGO_TARGET_DIR` вне репозитория, следи за диском (папка растёт на десятки ГБ: чисти `debug/incremental` или `cargo clean`).
- На всё в программе есть команда `devcast` (`open`, `close`, `config`, `record --app`, `app status|show|quit`, …). Живые проверки — командами, без физических кликов. Новая функция окна сразу получает команду CLI.
- Живые тесты с экраном, мышью и звуком — только когда владелец не за компьютером; не перехватывать фокус.
- Мелкие неясности — «как у других или как в DaVinci». Изменения архитектуры и SCOPE — не молча: вопрос в QUESTIONS.md.
- Снимки kittest принимать только после того, как посмотрел diff.
