# DevCast v2: архитектура

Технологии перепроверены 2026-10-27 по crates.io и GitHub. Версии фиксируются в `Cargo.lock` и обновляются только отдельной задачей.

## Стек

| Что | Чем | Почему, и на что смотреть |
|---|---|---|
| Язык | Rust stable (пин в `rust-toolchain.toml`) | Лучший результат агентов в SWE-bench Multilingual: Rust 58%, TS 35%, C/C++ 29%. Компилятор работает как ревьюер. |
| Интерфейс | egui/eframe 0.37 на wgpu 30 | UI — функция от состояния. Текстуры рендера показываются без копирования (`egui_wgpu::Callback` / `register_native_texture`, формат `Rgba8Unorm`). Пример большого приложения с таймлайном на egui — Rerun. **Внимание:** с 0.34 API другой (`App::logic` + `ui`, `run_ui`, `Panel`), а нейронки помнят старый, поэтому сверяемся с CHANGELOG egui. |
| Рендер кадра | wgpu 30 и свои WGSL-проходы | Фигуры — SDF-примитивы с градиентами, обводкой и прозрачностью. Blur — раздельный гауссов с даунсэмплом. Glow — blur альфы фигуры. Motion blur — несколько выборок вдоль скорости. Это просто и детерминировано. vello отклонён: он экспериментальный, без GPU-blur. tiny-skia отклонён: CPU и нет blur. |
| Кисть | lyon 1.0 | Тесселяция штрихов. |
| Текст | glyphon 0.12 на cosmic-text 0.19 | Тот же wgpu, работает кириллица. Цветные эмодзи и масштабирование в анимации проверяются пробой. |
| Видео: декодирование и кодирование | ffmpeg-next 9 + ffmpeg-sys-next, динамическая линковка с готовой shared-сборкой FFmpeg (GPL, с x264) | Так сделано у Cap. Аппаратные кодеки NVENC/QSV/AMF; на macOS и Linux VideoToolbox/VAAPI. **Самопроверка кодека:** закодировать и раскодировать серые кадры, иначе переходить к следующему; некоторые драйверы молча отдают нули. Крейт в режиме поддержки, поэтому для аппаратных контекстов возможен прямой вызов `ffmpeg-sys-next`. |
| Время звука | фильтр `atempo` FFmpeg (libavfilter) | Скорость участков с сохранением высоты тона. |
| Захват на Windows | windows-capture 2.0 (WGC) | Курсор отключён, рамка — где ОС позволяет (Windows 11; на Windows 10 видна на экране, в кадр не попадает). | Звук | cpal 0.18: WASAPI loopback и микрофон, воспроизведение; rubato (ресэмплинг), ebur128 (нормализация), nnnoiseless (шумоподавление, проверить в пробе) | В cpal 0.18 после создания потока нужно вызвать `play()`. Loopback шлёт «тихие» пакеты, тишину заполняем по таймстемпам. |

| GIF | gifski 1.34 | Лучшее качество. Лицензия AGPL совпадает с проектом. |
| Субтитры | whisper-rs 0.16 (whisper.cpp): Vulkan на Windows и Linux, Metal на macOS | Время слов через DTW (`flash_attn` при этом выключен). Модели GGML small и large-v3-turbo скачиваются с проверкой SHA-256 и докачкой: ureq (блокирующий, rustls), см. решение 010. |
| Связь CLI и редактора | interprocess 2.4: local socket (named pipe / unix socket), сообщения JSON с длиной в начале | Имя сокета своё для каждого пользователя. |
| Горячие клавиши и трей | global-hotkey 0.9, tray-icon 0.26 | Создаются на потоке цикла событий (в `CreationContext`). События передаются через обработчик и `request_repaint()`. |
| Установщик и обновления | Velopack (Rust SDK) | Windows, macOS и Linux, дельта-обновления, источник — GitHub Releases. `vpk` в CI требует .NET 8 SDK. |
| Логи и падения | tracing + tracing-appender (держать `WorkerGuard`), panic hook; crash-handler + minidumper для падений в нативном коде | |
| Схема проекта | serde + schemars | JSON Schema служит документацией для агента и для `devcast help`. |
| Тесты | cargo-nextest, insta (снимки), proptest; egui_kittest 0.37 (UI и снимки PNG); эталонные кадры рендера (dify / nv-flip); egui_inspection + egui_mcp (агент сам кликает по живому приложению и делает скриншоты) | Детали в [PROCESS.md](PROCESS.md). |

**Лицензия.** v2 выходит под AGPL-3.0, как и v1: алгоритмы переносятся из v1. Код Cap (AGPL/MIT) можно брать как образец, при копировании сохраняя уведомления. Крейт `dssim` не используем.

## Главные решения

1. **Проект — это папка `name.dcproj/`.**
   ```
   project.json      сохранённое состояние (Ctrl+S): маленький файл, читается глазами
   session.json      рабочее состояние: автосохранение и восстановление после вылета
   history.jsonl     журнал команд: undo/redo, общий для GUI и CLI
   media/            записи (сегменты → mp4), импортированные видео, звук, cursor.bin, keys.bin
   assets/           шрифты, картинки, курсоры, которые использует проект
   cache/            превью, волна, транскрипт, индексы ключевых кадров; можно удалить
   ```
   Если проект не открыт в редакторе, CLI применяет команду и сразу сохраняет. Если открыт, команда идёт в рабочее состояние редактора, и у названия появляется точка несохранённых изменений.
2. **Всё привязано ко времени исходника.** У каждого клипа своё source time. Нарезка, порядок клипов и скорость — это только карта времени source ↔ output. Если вырезать кусок, зумы, аннотации, субтитры и события курсора сдвигать не нужно. Эффекты на дорожках привязаны к записи (файл `Media.path` + время в нём), а не к клипу. Разрезание (как Blade в DaVinci) и перестановка клипов их не трогают, а настройки клипа (кроп, вырезы, скорость) копируются в обе половины. Исключения идут по времени выхода: дополнительные аудиодорожки и длительности анимаций (вход/выход аннотаций, печать облачка, эффекты кликов, анимации субтитров) — на ускоренном участке они идут с нормальной скоростью.
3. **Всё — команды.** Любое изменение — это `Command` из реестра: `apply(&mut Project) -> Result<Diff>`, и команда хранит обратную. Кнопка, хоткей, CLI и пакетный план идут одним путём. Другого способа изменить проект нет. Горячие клавиши тоже привязаны к командам, поэтому переназначить можно любую.
4. **Рендер — чистая функция в два шага.** `evaluate(project, t) -> Scene` работает на CPU, детерминирована и тестируется JSON-снимками. `draw(scene) -> кадр` работает на GPU. Превью, экспорт и `devcast frame` используют одно и то же.
5. **Эффект — вертикальный срез, один крейт.** В нём модель, команды, `evaluate`, `draw`, панель UI, справка для CLI и тесты. Новая фича — это новый крейт и одна строка регистрации.
6. **Писатель всегда один.** Если проект открыт в редакторе, CLI отправляет команды туда по IPC. Иначе CLI правит файлы под lock-файлом.
7. **Настройки по умолчанию** лежат в одном файле приложения. Новый проект копирует их к себе. «Сбросить» у группы возвращает значения по умолчанию, «Сбросить к заводским» — встроенные.
8. **Платформенный код** есть только в `capture/<os>`, `encode` (аппаратные кодеки), `update` и в мелких адаптерах `app` (трей, исключение окна из захвата).

**Правила зависимостей** (проверяет `cargo xtask verify`):
- `core` ни от кого не зависит.
- `fx/*` зависят только от `core`, API `render`, `ui-kit` и `egui`. Друг от друга они не зависят. Исключение: виды аннотаций зависят от `fx/annotations`.
- `app` и `cli` — верхний уровень, от них никто не зависит.

## Правила кода

- Файл — не больше 400 строк, функция — не больше 80.
- Вне тестов нет `unwrap` и `expect`, нет `unsafe` вне `capture` и `encode`. У каждого `unsafe` есть комментарий `SAFETY:`.
- Ошибки оформляются через `thiserror`, а текст ошибки объясняет, что делать.
- Типы схемы снабжаются doc-комментариями: из них собирается `devcast help`.
- В каждом крейте есть `CLAUDE.md` до 40 строк: зачем он, инварианты, как тестировать, куда не лезть. Корневой `CLAUDE.md` — до 150 строк.
- Процесс работы над задачей, проверки и правило «без костылей» описаны в [PROCESS.md](PROCESS.md).

## CLI для нейронки-монтажёра

**Принципы:**
- По умолчанию вывод короткий, `--json` — по запросу.
- Id короткие: `z3`, `a12`, `c2` (клип), `w140` (слово).
- Есть фильтры по времени.
- У всех изменяющих команд есть `--dry-run`.
- Ответ на изменение — одна строка с diff.
- Ошибка подсказывает, как её исправить.
- Картинки возвращаются путём к PNG.
- Результат пишется в stdout, ошибки в stderr, коды выхода 0, 1 или 2.

```
devcast help [cmd] [--json]
devcast record --source <screen:1|window:<id>|area:x,y,w,h> [--fps 60] [--duration 10] [--audio on|off] [--mic имя] [-o x.dcproj] | record stop|pause|resume|cancel
devcast ls sources                               # мониторы, окна, микрофоны для record
devcast new <video...> -o name.dcproj | clip add <video...> | clip move c2 --to 1 | clip split --at 12.5 | clip rm c2
devcast info | save
devcast ls <zooms|clips|annots|captions|tracks|clicks> [--from --to] [--fields]
devcast transcript [--from --to] [--words]       # текст с таймкодами и id слов
devcast silences [--min 0.5] [--db -30] [--track mic] [--from --to]   # паузы по готовому видео
devcast events <clicks|keys|activity> [--from --to]
devcast cut <10.2-12.5,...|w120-w135> [--dry-run]
devcast speed <from-to> <x>
devcast zoom suggest | zoom add --at <сек|clicks> [--duration 1] [--scale 1.8] [--mode follow|fixed] | zoom set z3 --scale 2 | zoom motion --preset smooth | zoom rm z3
devcast annot add <text|shape|image|blur|draw> --from --to --rect x,y,w,h [--rotate 15] [опции]

devcast callout add ... | keys show on|off

devcast crop c1 x,y,w,h | aspect <free|source|16:9|16:10|4:3>

```
