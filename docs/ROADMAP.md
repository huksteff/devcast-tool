**Порядок.** Этапы идут строго по очереди. Внутри этапа задачи идут по номерам, кроме помеченных ∥: их можно вести параллельно, когда готовы их зависимости.

**Контрольные точки.** В конце каждого этапа владельцу показывается демо (кадры, видео или скриншоты) и задаются накопившиеся вопросы. Затем идёт сессия уборки (см. PROCESS.md).

**Почему такой порядок:**
- запись идёт раньше рендера, чтобы тестовые записи сразу были в формате v2;
- рендер идёт раньше редактора, чтобы превью было готовым компоновщиком;
- CLI работает с этапа 2, и через него проверяется всё остальное.
