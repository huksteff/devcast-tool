# Этап 6. UI-основа и окна записи

**Цель:** общий UI-кит и всё, что видно во время записи.

**Проверка каждой UI-задачи:**
- снимок egui_kittest;
- живой прогон через egui_mcp со скриншотами;
- работа на двух мониторах с разным DPI, если это применимо.

- [ ] **6.1** Каркас `app` на eframe 0.37:
  - один экземпляр;
  - tracing с ротацией файлов, panic hook, crash-handler + minidumper;
  - CPU в простое около 0%;
  - dev-сборка с фичами eframe `inspection` + `accesskit`, `.mcp.json` проекта подключает `egui-mcp` для живой проверки агентом (решение 012).
- [ ] **6.2** `ui-kit`: тёмная тема, шрифты из `assets/fonts` (Inter, Montserrat, Roboto, PT Serif, JetBrains Mono, Noto Color Emoji, OFL + лицензии; `FontSystem` без системных шрифтов — решение 005), отступы, цвета, иконки.
- [ ] **6.3** `ui-kit`, виджеты ввода: кнопка, иконка-кнопка, переключатель, слайдер с полем числа, выпадающий список, поле ввода.
- [ ] **6.4** `ui-kit`, остальные виджеты:
  - выбор цвета и редактор градиента (2–4 цвета);
  - сворачиваемая группа с памятью состояния;
  - тост, диалог подтверждения, ошибка с кнопкой «Копировать».
- [ ] **6.5** Строки интерфейса на русском в одном модуле. Снимки kittest для каждого виджета.
- [ ] **6.6** Хранилище настроек приложения (один файл): папка записей, fps, отсчёт, микрофон, звук, хоткеи, модель Whisper, обновления.
- [ ] **6.7** HUD: окно поверх экрана (решение из пробы 1.1), исключено из захвата, перетаскивается, запоминает позицию на мониторе.
- [ ] **6.8** Выбор источника: сетка превью экранов и окон, подсветка выбранного, окно выходит на передний план.
- [ ] **6.9** Выбор области: стоп-кадр экрана в полноэкранном окне на каждом мониторе (решение 001), рамка с размерами, запоминание последней области.
- [ ] **6.10** Настройки в HUD: микрофон (список, индикатор уровня), системный звук, fps, отсчёт 0/3/5/10, «скрывать HUD из записи».
- [ ] **6.11** Обратный отсчёт: отменяется кликом или Esc.
- [ ] **6.12** Управление записью: таймер REC, пауза и продолжение, стоп, отмена с подтверждением, «скрыть HUD».
- [ ] **6.13** Трей: статус записи, «Остановить», «Показать панель», «Выход».
- [ ] **6.14** Глобальные горячие клавиши: старт/стоп, пауза, отмена. Настройка в окне настроек, показ конфликтов.
- [ ] **6.15** После стопа: «Подготовка записи» → открывается редактор с проектом. E2E: запись через HUD (kittest + живой прогон) даёт корректный проект.

**Готово, когда:** через HUD можно записать экран, окно и область, запись открывается, а HUD не попадает в видео.
