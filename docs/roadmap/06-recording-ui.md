# Этап 6. UI-основа и окна записи

**Цель:** общий UI-кит и всё, что видно во время записи.

**Проверка каждой UI-задачи:**
- снимок egui_kittest;
- живой прогон через egui_mcp со скриншотами;
- работа на двух мониторах с разным DPI, если это применимо.

  - CPU в простое около 0%;
  - dev-сборка с фичами eframe `inspection` + `accesskit`, `.mcp.json` проекта подключает `egui-mcp` для живой проверки агентом (решение 012).

Minidump — `crash.rs` (crash-handler + minidumper, единственный `unsafe` dc-app по решению владельца), дампы в `%APPDATA%\DevCast\crashes`. CPU в простое — в ночной живой проверке.

- [x] **6.11** Обратный отсчёт: отменяется кликом или Esc.
  Сделано: окно отсчёта (`countdown.rs`, макет 4): 200 × 200 по центру записываемого монитора, области или окна, число 88 px, «Клик или Esc — отмена», берёт фокус при открытии; в HUD «Запись» на это время — «Отменить N» (жёлтое число), клик отменяет. - [x] **6.15** После стопа: «Подготовка записи» → открывается редактор с проектом. E2E: запись через HUD (kittest + живой прогон) даёт корректный проект.
  Сделано: после стопа HUD показывает «Подготовка записи» (спиннер, макет 7), пока поток записи собирает дорожки и сохраняет проект; затем HUD прячется и открывается окно редактора (`editor.rs`, 1280 × 800, минимум 800 × 600) с проектом записи; закрытие редактора возвращает HUD. Сам редактор — этап 7 (7.1 строит раскладку), пока окно показывает имя проекта, число клипов, длину, размер кадра, путь и «Открыть папку проекта». Ошибка на этом шаге — панель ошибки в поповере HUD («Запись не подготовлена», «Копировать», «Открыть папку записи», «Закрыть»); запись остаётся в папке и восстанавливается. E2E (`e2e_tests.rs`, `#[ignore]`, пишет экран): kittest нажимает «Запись» и «Остановить запись» на полосе HUD (`hud::bar_ui` — весь HUD без родного окна), ждёт редактор и проверяет проект: один клип ≥ 2,5 с в папке записей с кириллицей и пробелом. Гоняется ночью: `DEVCAST_TEST_MONITOR=2 cargo nextest run -p dc-app --run-ignored only`. Автозумы после записи (настройка эффекта) в приложении пока не ставятся — см. вопрос в QUESTIONS.

**Готово, когда:** через HUD можно записать экран, окно и область, запись открывается, а HUD не попадает в видео.
