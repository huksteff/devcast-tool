# Этап 6. UI-основа и окна записи

**Цель:** общий UI-кит и всё, что видно во время записи.

**Проверка каждой UI-задачи:**
- снимок egui_kittest;
- живой прогон через egui_mcp со скриншотами;
- работа на двух мониторах с разным DPI, если это применимо.

- [x] **6.1** Каркас `app` на eframe 0.37:
  - один экземпляр;
  - tracing с ротацией файлов, panic hook, crash-handler + minidumper;
  - CPU в простое около 0%;
  - dev-сборка с фичами eframe `inspection` + `accesskit`, `.mcp.json` проекта подключает `egui-mcp` для живой проверки агентом (решение 012).
  Сделано: один экземпляр через канал dc-ipc `devcast-app-<пользователь>`, журнал с ротацией и паника в журнал, перерисовка только по событию, eframe с `inspection` + `accesskit`, `.mcp.json` с egui-mcp. Minidump не сделан: crash-handler требует `unsafe` (вопрос в QUESTIONS.md). CPU в простое — в ночной живой проверке.
- [x] **6.2** `ui-kit`: тёмная тема, шрифты из `assets/fonts` (Inter, Montserrat, Roboto, PT Serif, JetBrains Mono, Noto Color Emoji, OFL + лицензии; `FontSystem` без системных шрифтов — решение 005), отступы, цвета, иконки.
  Сделано: токены макета (`tokens.rs`), тёмная тема egui, шрифты Inter 400/500/600/700 (ось `wght` одной гарнитуры), JetBrains Mono, запасной Noto Color Emoji из папки `fonts` программы (`cargo xtask deps`; системных и встроенных egui нет), 23 линейные иконки фигурами; тестовый `testing::harness()` (FXC для WARP). Снимки `theme`, `icons_scale`. Файлы шрифтов в git не кладутся: их скачивает и копирует к программе `xtask deps`.
- [x] **6.3** `ui-kit`, виджеты ввода: кнопка, иконка-кнопка, переключатель, слайдер с полем числа, выпадающий список, поле ввода.
  Сделано: `widgets/`: `Button` (обычная, основная, опасная, призрачная, малая, со значком), `IconButton` (вкл., приглушена, текст «60», значок-число), `Toggle`, `segmented` (fps, отсчёт, пресеты), `Slider` с полем числа, `dropdown` (ComboBox egui в теме), `text_field`. Снимки и нажатия через AccessKit — `tests/inputs.rs`.
- [x] **6.4** `ui-kit`, остальные виджеты:
  - выбор цвета и редактор градиента (2–4 цвета);
  - сворачиваемая группа с памятью состояния;
  - тост, диалог подтверждения, ошибка с кнопкой «Копировать».
  Сделано: `color_button` (образец + HSV egui и поле hex), `gradient_editor` (2–4 цвета поровну, «+»/«−» гаснут на границах), `Section` (состояние в памяти egui по заголовку), `Toasts` (4 с, клик закрывает, перерисовка только к истечению), `Confirm` (Esc — отмена), `ErrorPanel` («Копировать», доп. кнопки, «Закрыть»), `panel_frame`. Снимок открытого HSV не делается: меши egui на WARP рисуются не одинаково от прогона к прогону. Попутно: снимок открытого списка показывает все пункты, выбранный пункт — белым текстом.
- [x] **6.5** Строки интерфейса на русском в одном модуле. Снимки kittest для каждого виджета.
  Сделано: `strings.rs`: все строки окон этапа 6 по макету (HUD, источник, область, отсчёт, настройки, горячие клавиши, трей, подготовка), шаблоны — функции; `tests/strings.rs` рисует каждую строку файла нашими шрифтами. Снимки есть у каждого виджета (`tests/inputs.rs`, `tests/other.rs`, `tests/theme.rs`).
- [x] **6.6** Хранилище настроек приложения (один файл): папка записей, fps, отсчёт, микрофон, звук, хоткеи, модель Whisper, обновления.
  Сделано: `settings.rs`: один файл `%APPDATA%\DevCast\settings.json` — папка записей, `RecordingConfig` (источник, fps, системный звук, микрофон), отсчёт 0/3/5/10, «скрывать HUD», хоткеи (Ctrl+Shift+R/P/X), модель Whisper (`fast`/`accurate`), обновления; один `Store` на все окна, запись сразу и атомарно. Окно настроек (deferred viewport): «Запись», «Субтитры», «Обновления», «О программе»; «Горячие клавиши» — в 6.14, умолчания эффектов — в редакторе. Модель выбирается радиокнопками egui, а не карточками макета; индикатор уровня микрофона — в 6.10.
- [x] **6.7** HUD: окно поверх экрана (решение из пробы 1.1), исключено из захвата, перетаскивается, запоминает позицию на мониторе.
  Сделано: HUD — главное окно: без рамки, поверх всех, без кнопки на панели задач, скругление DWM, исключение из захвата по «Скрывать HUD» (Win32 в `dc_capture::win::hud_window`), ручка перетаскивает окно (`StartDrag`), место запоминается на каждом мониторе (`hud/placement.rs`, новый — внизу по центру). Полоса по макету 1; кнопка «Ещё» открывает поповер (скрывать HUD, «Настройки», «Выход»). Полоса шире макета (≈ 480 px): имя источника «Экран 1 · 2560×1440» видно целиком. Живая проверка (DPI, два монитора, исключение из захвата) — ночью.
