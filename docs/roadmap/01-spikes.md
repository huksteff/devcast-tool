# Этап 1. Пробы

**Цель:** до основной работы проверить всё, что может не взлететь.

**Правила проб:**
- Каждая проба — минимальный код в `spikes/<имя>/`.
- Результат — запись `docs/decisions/NNN-<тема>.md`: что проверили, цифры, решение.
- Если проба провалилась, переходим на описанный запасной вариант. Если запасного нет или он заметно хуже, задаём вопрос владельцу.
- Код проб не идёт в продукт. Переносятся только выводы.

- [x] **1.1** ∥ **Прозрачный HUD.** eframe/wgpu на DX12 в режиме `DxgiFromVisual`: окно прозрачное, поверх всех, пропускает клики (MousePassthrough включается после показа окна) и исключено из захвата (`WDA_EXCLUDEFROMCAPTURE`). Проверить на доступных GPU NVIDIA, AMD и Intel.

  Запасной вариант: непрозрачное окно без рамки, исключённое из захвата. Для выбора области — стоп-кадр экрана в полноэкранном окне на каждом мониторе.
- [x] **1.2** ∥ **Несколько окон.** Редактор, отдельный таймлайн и HUD одновременно. Проверить:
  - что второе окно не замирает, когда фокус в главном (egui #8466);
  - что смена DPI между мониторами работает;
  - что в простое CPU около 0%.
- [ ] **1.3** ∥ **Видео в окне.** ffmpeg-next (d3d11va) → NV12 → две текстуры (R8 + RG8) → шейдер → egui. Цели:
  - 1080p60 и 4K30 без пропусков;
  - seek к произвольному кадру быстрее 100 мс при GOP 2 с.

  Зафиксировать способ сборки FFmpeg: готовая shared-сборка, `FFMPEG_DIR`, DLL рядом с exe.
- [ ] **1.4** ∥ **Фигуры и эффекты на WGSL:**
  - SDF-прямоугольник, эллипс и стрелка с градиентом в 4 цвета, обводкой и поворотом;
  - раздельный гауссов blur области;
  - glow.

  Производительность в 4K60 на встроенной графике.
- [ ] **1.5** ∥ **Текст.** glyphon:
  - кириллица в нескольких шрифтах;
  - цветные эмодзи;
  - анимированное масштабирование ×1→×3 без мыла.

  Пользовательский .ttf из файла.
- [ ] **1.6** ∥ **Экспорт.** Рендер без окна → NV12 → `h264_nvenc` / `h264_qsv` / `h264_amf` / `libx264`. Самопроверка: закодировать и раскодировать серые кадры, при сбое перейти к следующему кодеку. Замерить скорость против v1 на одном ролике.
- [ ] **1.7** ∥ **Захват.** windows-capture: монитор, окно и область (кроп на GPU), без курсора и жёлтой рамки, PTS по QPC. Записать 10 минут с переменной частотой кадров.
- [ ] **1.8** ∥ **Звук.** cpal loopback и микрофон одновременно:
  - тишина заполняется по таймстемпам;
  - устройство отключается и подключается во время записи;
  - расхождение с видео за 10 минут меньше 1 кадра.

  Проверить nnnoiseless на шумной записи.
- [ ] **1.9** ∥ **Хуки ввода.** WH_MOUSE_LL и WH_KEYBOARD_LL на отдельном потоке:
  - нет потерь при быстрых кликах;
  - что происходит над окнами с правами администратора;
  - картинки курсора (стрелка, I-beam, рука, ресайз).

  Обычный ввод текста не сохраняется.
- [ ] **1.10** ∥ **Whisper.** Сборка whisper-rs с Vulkan на Windows (CMake, clang, Vulkan SDK). Русская речь на large-v3-turbo и small: качество, скорость, точность времени слов (DTW) на 3 фикстурах.

  Запасной вариант: whisper.cpp отдельным процессом.
- [ ] **1.11** ∥ **IPC.** interprocess local socket: команда из CLI меняет состояние открытого окна быстрее 100 мс. Повторное подключение, когда редактора нет.
- [ ] **1.12** ∥ **Тесты в CI.** egui_kittest-снимок и эталонный кадр компоновщика на GitHub `windows-latest` (WARP) дают одинаковый результат при 10 прогонах. Также проверить egui_inspection + egui_mcp: агент кликает по живому окну и получает скриншот.
- [ ] **1.13** ∥ **Velopack.** Установщик для текущего пользователя, обновление (полное и дельта) из тестового публичного репозитория, сохранность настроек при обновлении.
- [ ] **1.14** **Итог проб:**
  - обновить ARCHITECTURE.md и SCOPE.md по результатам;
  - удалить `spikes/`;
  - составить список вопросов владельцу, если что-то не взлетело.

**Готово, когда:** по каждой пробе есть решение, вопросы владельцу заданы и закрыты.
