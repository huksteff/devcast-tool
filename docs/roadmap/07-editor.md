# Этап 7. Редактор

**Цель:** полный редактор поверх готового рендера и команд. Любое действие в UI — это команда из реестра.

**Проверка каждой UI-задачи:**
- снимок egui_kittest;
- живой прогон через egui_mcp со скриншотами;
- один и тот же результат через UI и через CLI (сравнить `project.json`).

**Каркас**
- [ ] **7.1** Раскладка: превью, боковая панель эффектов, таймлайн, шапка (название с переименованием, точка несохранённых), меню.
- [ ] **7.2** Подключение к `ops` и истории: все действия UI идут через команды; Ctrl+Z / Ctrl+Y, в том числе в русской раскладке.
- [ ] **7.3** Горячие клавиши через реестр команд: каждую команду можно переназначить, есть справка (полный список).
- [ ] **7.4** Превью: текстура компоновщика без копирования, масштаб превью, качество превью при нехватке производительности.
- [ ] **7.5** Воспроизведение:
  - часы — позиция аудиовыхода, а без звука — `Instant`;
  - пропуск отставших кадров;
  - громкость превью;
  - Space, стрелки (покадрово), переход к ключевому кадру или ±5 с.

**Таймлайн**
- [ ] **7.6** Вьюпорт: шкала времени, масштаб, прокрутка, полоса навигации, высота панели и дорожек (Shift+колесо).
- [ ] **7.7** Указатель: перетаскивание, клик по шкале, автопрокрутка у края.
- [ ] **7.8** Главная дорожка:
  - клипы, магнитная перестановка;
  - разрезание (C), удаление клипа;
  - участки скорости.
- [ ] **7.9** Общий механизм регионов:
  - выделение и мультивыделение;
  - перемещение, изменение длины;
  - привязка к краям и указателю;
  - Ctrl+C/X/V, Ctrl+A, Delete.
- [ ] **7.10** Дорожки:
  - зумы, аннотации (несколько, порядок = слои), субтитры, события курсора и облачка, аудио;
  - добавление и удаление (подтверждение для непустых);
  - «призрак» быстрого добавления.
- [ ] **7.11** Волна звука на аудиодорожках.
- [ ] **7.12** Маркеры кейфреймов: показать или скрыть, выбор, перенос по времени.

**Связка и качество**
- [ ] **7.32** IPC-сервер в редакторе: команды CLI для открытого проекта применяются вживую и попадают в общий undo.

- [ ] **7.34** Производительность:
  - превью 1080p60 без пропусков;
  - таймлайн с 500 регионами плавный;
  - CPU в простое около 0%, разумная память;
  - аппаратное декодирование (D3D11VA) с запасным вариантом на CPU и передачей кадра в wgpu без копирования — если CPU на 4K окажется проблемой (решение 003; перенесено из 4.3: с копированием в память оно медленнее программного, и нужен unsafe — тогда же решить, в каком крейте).
