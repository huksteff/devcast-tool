# Этап 7. Редактор

**Цель:** полный редактор поверх готового рендера и команд. Любое действие в UI — это команда из реестра.

**Проверка каждой UI-задачи:**
- снимок egui_kittest;
- живой прогон через egui_mcp со скриншотами;
- один и тот же результат через UI и через CLI (сравнить `project.json`).
