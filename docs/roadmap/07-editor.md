# Этап 7. Редактор

**Цель:** полный редактор поверх готового рендера и команд. Любое действие в UI — это команда из реестра.

**Проверка каждой UI-задачи:**
- снимок egui_kittest;
- живой прогон через egui_mcp со скриншотами;
- один и тот же результат через UI и через CLI (сравнить `project.json`).

Редактор (`editor/keys.rs`) ищет нажатое в таблице и выполняет действие; подключены отмена/повтор, «Выбор»/«Лезвие», привязка, справка. Остальные действия зарегистрированы без обработчика (его добавит своя задача в `keys::act`): в справке и настройках они серые с подсказкой «Пока не работает» — список честный и полный сразу. Пока открыта справка или поле ввода, клавиши редактора молчат. - [ ] **7.4** Превью: текстура компоновщика без копирования, масштаб превью, качество превью при нехватке производительности.
  Сделано (2026-10-31): одно устройство `dc_render::Gpu` на окна и превью (`gpu.rs`: eframe получает его клоны через `WgpuSetup::Existing`, `Shared::gpu` — оно и рендерер egui). Кадр рисует поток `devcast-preview` (`editor/preview/worker.rs`) путём `devcast frame` и экспорта: `Evaluator` (строится раз на ревизию проекта; телеметрия — общая `dc_capture::project::telemetry_tracks`, её теперь зовёт и CLI) → `dc_encode::Sources` (декодирование) → `Compositor::draw` в текстуру устройства; текстура регистрируется в egui как родная (`register_native_texture`, без копии через CPU и без unsafe), одна на размер. Берётся только новейший запрос, ответ несёт поколение (`fetch.rs`), последний кадр виден до нового, ошибка (нет клипов, битое видео) пишется на кадре. Поток будит главное окно, а оно — редактор (`Preview::take_news`); в простое ничего не перерисовывается. Запрос — при смене ревизии (команды 7.2, undo/redo), `View::playhead` и размера рендера. «Вписать / 50% / 100%» — `fit::frame_rect`, больше области — прокрутка; «Полное» — пиксели кадра на экране, но не больше выхода, «Быстрое» — половина каждой стороны (`fit::render_size`). Тесты: математика размеров, машина запросов с поддельным потоком, на WARP кадр потока = кадр `devcast frame` побайтно (`worker_tests.rs`, фикстура `clicks.dcproj`), переиспользование текстуры, проект без клипов. Ближайший ключевой кадр, пока тянут указатель (решение 003), — в 7.7. Живой прогон через egui-mcp делает владелец.
