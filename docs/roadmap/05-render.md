# Этап 5. Рендер и экспорт

**Цель:** один компоновщик для превью, экспорта и CLI. Все эффекты из SCOPE. Экспорт MP4 и GIF из CLI.

**У каждого эффекта своя проверка:**
- снимки `evaluate` в 10–20 моментах;
- 2–4 эталонных кадра;
- визуальная сверка `sheet` с эталоном v1.

**Каркас render** (последовательно)
- [x] **5.1** wgpu-устройство: общее для окна и рендера без окна, выбор адаптера, режим без окна для CI (WARP / lavapipe).
- [x] **5.2** `Scene` — результат `evaluate`. Проходы, порядок слоёв, кэш ресурсов.
- [x] **5.3** Видеопроход:

- [x] **5.4** SDF-фигуры: прямоугольник со скруглением, эллипс, линия, стрелка; градиент 2–4 цвета (в том числе анимированный), обводка, прозрачность, поворот.
- [x] **5.5** Раздельный гауссов blur с даунсэмплом, blur области с тонировкой, glow.
