  Реализация — общий `dc-agent` для GUI и CLI через штатный app-server (решение 021). Codex получает один клиентский инструмент `devcast`; общая оболочка, сторонние инструменты и MCP отключены, модель read-only, дополнительные разрешения закрыты. До первого запроса проверяются конфигурация и MCP-инвентарь. Клиент фиксирует исполняемый файл DevCast, папку проекта и `DEVCAST_GROUP`; правки проходят через существующие CLI, реестр и IPC. Продолжение — `thread/resume`, каждый запуск отменяется одним шагом.

  Модель выбирается из общего выпадающего списка DevCast. Каталог загружается в фоне через `model/list` установленного Codex, с пагинацией и без скрытых моделей. Доступны «По умолчанию» и ранее заданная модель; смена агента и «Проверить снова» обновляют каталог. Ошибки загрузки видны пользователю.

  Проверки: тесты поиска, входа, запуска и продолжения, ограничения инструментов и отмены, настроек и установки скилла; снимки интерфейса. Инструкция — [docs/CODEX.md](../CODEX.md). Для приёмки остаются живой монтаж настоящим Codex на тестовом проекте, продолжение разговора, проверка единого шага отмены и выполнение сценария из SCOPE через установленный скилл; клики в интерфейсе проверяет владелец.
