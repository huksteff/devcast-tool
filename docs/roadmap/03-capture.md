# Этап 3. Запись (Windows, движок без UI)

**Цель:** `devcast record` пишет экран, звук, курсор и клавиши надёжно и синхронно. Появляются настоящие фикстуры v2.

- [x] **3.1** Трейт `Recorder`. Типы источника (монитор, окно, область), `RecordingConfig` (fps 30/60/120, звук, микрофон), события записи.
- [x] **3.2** Список источников: мониторы и окна с кадрами-превью, основной монитор, понятные имена окон.
- [x] **3.3** Видео через windows-capture:
  - монитор, окно, область (кроп на GPU);
  - без курсора и рамки;
  - PTS по QPC.
- [x] **3.4** Кодирование на лету: H.264, GOP 1 с (решение 003), самопроверка аппаратного кодека, запасной вариант на CPU. При 120 fps проверить, что кодек справляется, а если нет — внятная ошибка.
- [x] **3.5** Сегменты fMP4 по каждой дорожке и `manifest.json` с атомарной записью. По стопу финализация в MP4.
- [x] **3.6** Восстановление после вылета: отбросить неполный сегмент и собрать проект из целых.

  Проверка: принудительно убить процесс во время записи, после чего запись открывается.
- [x] **3.7** Системный звук (cpal loopback): тишина заполняется по таймстемпам, в том числе до первого и после последнего пакета (в тишине loopback ничего не присылает); дрейф часов устройства компенсируется ресэмплингом к шкале QPC (решение 008); при смене устройства вывода запись продолжается.
- [x] **3.8** Микрофон: выбор устройства, поток уровня для индикатора, запоминание выбора.
- [ ] **3.9** Синхронизация: общая шкала QPC для видео, звука и ввода.

  Проверка: ночной тест на 30 минут, расхождение меньше 1 кадра.
- [x] **3.10** Мышь (WH_MOUSE_LL на своём потоке): позиция, кнопки, колесо, без потерь. Двоичный `cursor.bin` со схемой.
- [x] **3.11** Картинки и тип курсора: `GetCursorInfo` → PNG, кэш по HCURSOR, дедупликация, тип (стрелка, I-beam, рука, ресайз, «нельзя»). Монохромные курсоры (I-beam) — по маскам AND/XOR, «инверсия» рисуется чёрным с белым контуром (решение 009).
- [x] **3.12** Клавиши (WH_KEYBOARD_LL): только сочетания с Ctrl, Alt или Win и спецклавиши. Обычный ввод не сохраняется никогда.

  Проверка: тест на то, что `abc` не попадает в файл.
- [ ] **3.13** Пауза и продолжение (разрыв во времени, один проект). Отмена удаляет все файлы.

  Код и юнит-тесты готовы (решение 007, «Задача 3.13»); живой тест `tests/pause.rs` ждёт ночного прогона.
- [ ] **3.14** По стопу создаётся проект `.dcproj`: клип, дорожки, телеметрия, настройки по умолчанию.

  Код и юнит-тесты готовы (решение 007, «Задача 3.14»; координаты — решение 009); живой тест `tests/project.rs` ждёт ночного прогона.
- [ ] **3.15** CLI:
  - `devcast record --source ... --fps ... [--duration]`;
  - `record stop`, `record pause`;
  - `devcast ls sources`.
- [ ] **3.16** Фикстуры v2. Записать через CLI 6 коротких роликов (Git LFS):
  - клики;
  - печать с сочетаниями клавиш;
  - речь в микрофон;
  - системный звук;
  - быстрое движение курсора;
  - запись окна.

  Плюс описание каждого.

**Готово, когда:** фикстуры записаны, запись переживает вылет, 30 минут без рассинхрона.
