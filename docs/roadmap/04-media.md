# Этап 4. Медиа и анализ

**Цель:** декодирование, звук, поиск тишины, транскрипт и автозумы. Сценарий «вырежи паузы и оговорки» работает через CLI.

**media**
- [ ] **4.1** Probe: длительность, потоки, fps, разрешение, переменная частота кадров. Индекс ключевых кадров кэшируется в `cache/`.
- [ ] **4.2** `devcast new <video...>` и `devcast clip add|ls|move`: импорт mp4/mov/mkv/webm в проект (без телеметрии курсора).
- [ ] **4.3** Декодер:
  - аппаратное ускорение с запасным вариантом на CPU;
  - seek: ключевой кадр, затем декодирование вперёд до точного PTS;
  - счётчик поколений seek, чтобы отбрасывать устаревшие кадры;
  - пул кадров с ограничением памяти.

  Проверка: точный кадр на 50 случайных позициях.
- [ ] **4.4** Кадр-превью для библиотеки и списка проектов.

**audio**
- [x] **4.5** Декодирование всех дорожек в общий формат (48 кГц, float), ресэмплинг через rubato.
- [x] **4.6** Микс по карте времени: вырезы без щелчков (короткие фейды на стыках), скорость с сохранением высоты тона через `atempo`.
- [x] **4.7** Уровни: громкость 0–100%, усиление до 10× без цифрового клиппинга (лимитер), mute и уровни каналов для каждого клипа.
- [ ] **4.8** Нормализация EBU R128 (ebur128): целевая громкость и проверка результата измерением.
- [ ] **4.9** ∥ Шумоподавление микрофона (nnnoiseless) как фильтр дорожки. Исходник не меняется.
- [ ] **4.10** ∥ Пики волны для таймлайна с кэшем на нескольких масштабах.
- [ ] **4.11** ∥ Поиск тишины → `devcast silences --min --db`.

  Проверка: разметка на фикстуре с речью совпадает с ручной.

**transcribe**
- [ ] **4.12** Модели: скачивание small и large-v3-turbo с прогрессом, проверкой SHA-256 и докачкой. Хранятся в данных приложения.
- [ ] **4.13** Распознавание: whisper-rs (Vulkan; см. вопрос про Vulkan SDK), язык авто или выбранный, слова с таймкодами (DTW, `flash_attn = false`, вычесть калиброванный сдвиг ~0,26 с — решение 010), выбор дорожек (по умолчанию микрофон). Результат кэшируется.
- [ ] **4.14** Разбиение слов на реплики по правилам из выжимки 0.13.
- [ ] **4.15** `devcast transcript [--words]` с id слов; `devcast cut w120-w135`: границы слов привязываются к ближайшему минимуму громкости (≤ 150 мс), чтобы не резать звук посреди слова (решение 010).

**События и автозумы**
- [ ] **4.16** ∥ `devcast events clicks|keys|activity` по телеметрии курсора и клавиш.
- [ ] **4.17** Автозумы:
  - паузы курсора и кластеры кликов по выжимке 0.10;
  - `devcast zoom suggest` и `zoom add --at clicks`;
  - склейка близких;
  - автозумы сразу после записи (настройка).
- [ ] **4.18** E2E «вырежи паузы и оговорки» на фикстуре с речью.

  Проверка: итоговая длительность, отсутствие вырезанных слов в транскрипте после монтажа, число вызовов CLI.

**Готово, когда:** сценарий 4.18 проходит, транскрипт на русском читаемый, а автозумы на фикстуре с кликами стоят там, где ожидается.
