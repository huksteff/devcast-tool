# Этап 2. Ядро и CLI (без рендера)

**Цель:** модель проекта, команды, история, папка проекта и CLI. Всё проверяется на синтетических проектах из `fixtures/projects/`.

**Инструменты**
- [x] **2.0** `cargo xtask deps`: скачать FFmpeg (BtbN, датированный тег) и libclang (PyPI) в `.deps/` с проверкой SHA-256, прописать `FFMPEG_DIR` и `LIBCLANG_PATH` в `.cargo/config.toml`, копировать DLL рядом с собранными exe. CI делает то же (решение 003).

**core**
- [x] **2.1** Время: `SourceTime`, `OutputTime` (микросекунды, i64), `Range`, арифметика без переполнений.

  Проверка: proptest на граничных значениях.
- [ ] **2.2** Короткие типизированные id (`z3`, `a12`, `c1`, `w140`): генерация без повторов, парсинг, понятная ошибка на чужой префикс.
- [ ] **2.3** Геометрия: нормализованные координаты кадра, `Rect` / `Point` / `Size`, поворот, перевод в пиксели.
- [ ] **2.4** Структура `Project`: клипы, дорожки, настройки эффектов (через реестр). serde + schemars, doc-комментарии на всех полях.
- [ ] **2.5** Карта времени:
  - несколько клипов на главной дорожке;
  - вырезы;
  - участки скорости 0,25–16×;
  - перевод source ↔ output в обе стороны.

  Проверка: proptest-инварианты (монотонность, обратимость, сумма длительностей).
- [ ] **2.6** Трейт `Command`, `Diff`, обратная команда. История undo/redo; пакет команд — одна запись в истории.
- [ ] **2.7** Трейт `Effect` (id, настройки по умолчанию, схема, команды) и реестр эффектов.

**project**
- [ ] **2.8** Папка `.dcproj`: создание, чтение, запись. Атомарная запись: tmp → fsync → rename → fsync каталога. Пути с кириллицей и пробелами.
- [ ] **2.9** Рабочее состояние `session.json` и сохранённое `project.json`:
  - автосохранение с задержкой;
  - флаг «есть несохранённое»;
  - «Сохранить» и «Сохранить как»;
  - восстановление после вылета.
- [ ] **2.10** Lock-файл одного писателя. Распознаётся «мёртвый» lock после падения процесса.
- [ ] **2.11** `history.jsonl`: история хранится между запусками, есть ограничение размера, повреждённая строка не ломает загрузку.
- [ ] **2.12** Настройки по умолчанию приложения: файл, заводские значения, применение к новому проекту, «сохранить текущие как по умолчанию».
- [ ] **2.13** Версия схемы и механизм миграций. Пока миграций нет, но цепочка уже тестируется.

**ops и CLI**
- [ ] **2.14** `ops`: реестр всех команд из эффектов, `apply`, `dry-run`, план из JSON как одна транзакция (всё или ничего).
- [ ] **2.15** Вывод: однострочный diff (`+3 zooms z12..z14; 3:12→2:58`). Ошибки с подсказками (`z99 not found (z1..z14); try: devcast ls zooms`).
- [ ] **2.16** Каркас CLI на clap:
  - глобальные `--project`, `--json`, `--dry-run`;
  - поиск проекта в текущей папке;
  - коды выхода, разделение stdout и stderr.
- [ ] **2.17** `devcast help`:
  - список команд, одна строка на команду;
  - справка по одной команде с примером;
  - `--json` со схемой.
- [ ] **2.18** `devcast info`, `ls`: фильтры `--from` / `--to`, `--fields`, постраничный вывод больших списков.
- [ ] **2.19** `devcast apply`, `undo`, `redo`, `history`, `save`.
