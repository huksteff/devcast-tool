# 001. Окно HUD и оверлеи (проба 1.1)

Дата: 2026-10-28. Код пробы: `spikes/hud`.
Проверено на Windows 11 26100, NVIDIA RTX 3060 Ti, два монитора (2560×1440 и 1920×1080). На AMD и Intel не проверено — это делается в задаче 8.7.

## Что проверяли

Прозрачное окно поверх всех на eframe 0.37 + wgpu 30 (DX12), с пропуском кликов и исключением из захвата.

## Результаты

| Вариант | Результат |
|---|---|
| Прозрачное окно, swapchain `DxgiFromVisual` | Прозрачная часть **белая** |
| Прозрачное окно, swapchain `DxgiFromHwnd` | Прозрачная часть **чёрная** |
| `WS_EX_NOREDIRECTIONBITMAP`, выставленный после создания окна | Не помогает: флаг работает только при создании окна, а egui-winit его при создании не задаёт |
| Непрозрачное окно размером с панель, скругление углов от DWM | Выглядит как панель со скруглёнными углами, без фона вокруг |
| То же + `SetWindowDisplayAffinity(WDA_EXCLUDEFROMCAPTURE)` | На скриншоте экрана окна нет; `WindowFromPoint` в этой точке возвращает наше окно — для пользователя оно видно и кликабельно |

## Решение

**Прозрачных окон в v2 нет.** Так проще: не нужно патчить egui и писать своё окно в обход eframe.
- **HUD** — непрозрачное окно без рамки ровно по размеру панели:
  - скругление углов через `DWMWA_WINDOW_CORNER_PREFERENCE = DWMWCP_ROUND` (на Windows 10 углы останутся прямыми);
  - поверх всех окон, без значка на панели задач;
  - исключено из захвата через `WDA_EXCLUDEFROMCAPTURE`.
- **Выпадающие панели HUD** (микрофон, отсчёт и т.п.) — отдельные маленькие окна того же вида или увеличение окна HUD.
- **Выбор области** — стоп-кадр экрана в полноэкранном непрозрачном окне на каждом мониторе: затемнение и рамка рисуются поверх стоп-кадра.
- **Пропуск кликов** не нужен: прозрачных частей нет.

## Попутно

- Во встроенных шрифтах egui нет символа «●» (рисуется квадратиком). Значки рисуем фигурами или берём шрифт с нужными символами — задача 1.5 / 6.2.
- API eframe 0.37: `App::logic` + `App::ui(ui, frame)`, `clear_color`, `NativeOptions::wgpu_options.wgpu_setup` (через `WgpuSetup::CreateNew` задаются backend и `Dx12SwapchainKind`).
- Окно консоли: в релизе бинарник собирается с `windows_subsystem = "windows"`.
