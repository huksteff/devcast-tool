# 013. Установщик и обновления: Velopack (проба 1.13)

Дата: 2026-10-28. Код пробы: `spikes/velopack`. Крейт velopack 1.2.161 и утилита `vpk` 1.2.161 (dotnet tool). Версии должны совпадать.

## Окружение сборки

- `vpk` — dotnet tool, нужен .NET SDK. .NET 8 SDK официальным скриптом не поставился (канал 8.0 не нашёл SDK 8.0.427). Поставлен .NET **10.0.403 (LTS)** через `dotnet-install.ps1 -Channel LTS` в `%LOCALAPPDATA%\Microsoft\dotnet`, без прав администратора. `dotnet tool install -g vpk` с ним работает.
- В CI: `actions/setup-dotnet` (LTS) + `dotnet tool install -g vpk` (задача 8.6).

## Результаты (Windows 11, без прав администратора)

| Шаг | Результат |
|---|---|
| `vpk pack 1.0.0` | установщик `Setup.exe` 10,4 МБ, полный пакет 2,8 МБ, portable zip, `releases.win.json` |
| `Setup.exe --silent` | установка в `%LOCALAPPDATA%\DevCastSpike`; ярлыки на рабочем столе и в «Пуске»; запись для удаления в HKCU; хук `--veloapp-install` отработал за 91 мс |
| `vpk pack 1.0.1` | дельта 1.0.0 → 1.0.1 весит **5,5 КБ** против 2,8 МБ полного пакета |
| Обновление из локальной папки (`FileSource`) | 1.0.0 нашла 1.0.1 (одна дельта), скачала, применила и **перезапустилась как 1.0.1** с переданными аргументами |
| Настройки вне папки установки | счётчик запусков пережил обновление (1 → 2 → 3) |
| `Update.exe uninstall --silent` | удалены папка, ярлыки и ключ реестра |

## Решение

- Установщик и обновления — Velopack.
  - `VelopackApp::build().run()` вызывается первой строкой `main`: так обрабатываются хуки установки и удаления.
  - Источник обновлений — `GithubSource` на GitHub Releases нашего репозитория. Пока репозиторий приватный, обновления выключены (SCOPE), локально механизм проверяется через `FileSource`.
- Настройки и данные приложения хранятся вне папки установки (`%LOCALAPPDATA%\DevCast\…` или `%APPDATA%`). Папка установки при обновлении целиком заменяется.
- Логика UI «Скачать? / Не сейчас / Пропустить версию / бета-канал» — своя, поверх `check_for_updates` / `download_updates` / `apply_updates_and_restart` (задача 8.2).
- Сборка пакета (8.1): `cargo xtask package` → `<папка сборки>/velopack/releases`; id пакета `DevCast` менять нельзя (по нему Velopack находит установку).
- Подпись установщика: `vpk` предупреждает, что файлы не подписаны. Сертификата нет, это вопрос к владельцу на этапе 8.

## Выбор папки установки (2026-11-04)

Velopack сам не спрашивает, куда ставить, но его установщик принимает `--installto <папка>` (проверено: ставит туда, обновления идут туда же, удаление чистое). Владелец захотел выбор папки — поверх Velopack сделана маленькая программа `DevCast-Setup.exe` (крейт `dc-setup`): системный вопрос «Установить в %LOCALAPPDATA%\DevCast / Другая папка… / Отмена» и вшитый `DevCast-win-Setup.exe` с `--installto`. Другой установщик (Inno Setup, MSI) отвергнут: обновления пришлось бы писать самим.
