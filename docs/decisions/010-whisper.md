# 010. Распознавание речи Whisper (проба 1.10)

Дата: 2026-10-28. Код пробы: `spikes/whisper`.
Тестовая речь — 45,6 с русского текста, синтезатор Windows (голос Irina, 16 кГц моно). Точное время начала каждого слова получено из событий синтезатора `SpeakProgress` (68 слов). Модели GGML с `huggingface.co/ggerganov/whisper.cpp`:
- `ggml-small.bin` — 488 МБ, SHA-256 `1be3a9b2…a987b`;
- `ggml-large-v3-turbo.bin` — 1,62 ГБ, SHA-256 `1fc70f77…2bc69`.

## Качество (русский, язык задан явно)

| Модель | WER (ошибки в словах) | Текст |
|---|---|---|
| small | 1,4% | одна лишняя «к» («ссылку к коллегам»), «ё» → «е» |
| large-v3-turbo | 0,0% | совпадает с эталоном, даже знаки препинания |

Речь синтетическая и чистая. На живой речи с шумом ошибок будет больше; повторить на фикстурах 3.16.

## Скорость

| Вариант | small | large-v3-turbo |
|---|---|---|
| whisper-rs, CPU, 16 потоков, greedy | 61,5 с (×0,7 реального времени) | 234,6 с (×0,2) |
| whisper-cli из официальной сборки CUDA 12.4 (b5454), RTX 3060 Ti, без DTW | ~2,7 с вместе с загрузкой модели (~×17) | ~2,6 с (~×17) |

На CPU turbo непригоден: 4 минуты на 45 секунд. Нужна видеокарта.

## Время слов

Сравнение с эталоном на первых 12 словах:
- **`t0` (время токена)** у small ошибается в среднем на 0,19 с, отдельные слова до 0,44 с. У turbo `t0` систематически раньше примерно на 1 с — непригоден.
- **DTW** (`DtwModelPreset::Small` / `LargeV3Turbo`) у обеих моделей стабильно позже начала слова на +0,10…+0,46 с, в среднем на +0,26 с. После вычета среднего сдвига остаётся около 0,09 с. Это лучший источник.
- DTW не работает при включённом flash attention: в whisper-cli он включён по умолчанию, и `t_dtw = -1`. Нужен флаг `-nfa` / `flash_attn(false)`. Проверка CUDA + DTW + `-nfa` не завершена: запуск был отклонён автоматической проверкой безопасности.

## Сборка

- whisper-rs 0.16 (whisper.cpp внутри) **на CPU** собирается за ~35 с с портативным CMake 4.4.5 (zip без установки, `.deps/cmake`) и MSVC.
- **GPU-бэкенд** whisper-rs требует при сборке Vulkan SDK (`vulkan` feature) или CUDA Toolkit (`cuda`). Оба ставятся только с правами администратора — отложено (`docs/QUESTIONS.md`). Пользователям SDK не нужен: Vulkan-рантайм приходит с драйвером видеокарты.
- У whisper.cpp есть официальная сборка `whisper-bin-win-cuda-12.4.0-x64.zip` (685 МБ из-за cuBLAS). Она работает без установки CUDA, только на NVIDIA.

## Решение (предварительное, ждёт ответа владельца)

- **Рекомендация: whisper-rs внутри процесса с бэкендом Vulkan.** Одна сборка для NVIDIA, AMD и Intel, без 685 МБ cuBLAS. На CPU — запасной вариант для машин без подходящей GPU (тогда по умолчанию модель «Быстрая»).
  - Нужно один раз поставить Vulkan SDK на машину разработки и в CI.
  - Запасной путь, если Vulkan не взлетит: sidecar `whisper-cli` из официальной сборки CUDA, качается при первом использовании, как модели.
- **Время слов — DTW**, `flash_attn = false`.
  - Сдвиг ~0,26 с калибруется на фикстурах 3.16 и вычитается.
  - Для вырезания слов (`cut w120-w135`) границы дополнительно привязываются к ближайшему минимуму громкости (≤ 150 мс), чтобы не резать звук посреди слова (задача 4.15).
- **Модели** качаются с HuggingFace с проверкой SHA-256 (хэши выше).

## Загрузка моделей (задача 4.12)

- **HTTP-клиент — ureq 3** (`default-features = false`, `rustls`: ring + встроенные корневые сертификаты webpki-roots).
  - Блокирующий, без tokio и async: загрузка идёт в своём потоке, отмена — флаг между кусками по 64 КБ.
  - rustls не зависит от системного OpenSSL/SChannel; DLL к exe не добавляются.
  - Следует редиректам HuggingFace на CDN и сохраняет заголовок `Range` (проверено: CDN отвечает 206).
  - Отвергнуты: reqwest (тянет tokio и hyper даже в blocking-режиме), системный `curl` (как в `xtask deps`; у пользователя может не оказаться, нет прогресса и отмены из кода).
- **Где лежат:** `%APPDATA%\DevCast\models` (рядом с настройками, `dc_project::settings::dir()`).
- **Атомарность:** качается в `<файл>.part`, после загрузки весь файл проверяется SHA-256 и переименовывается. Файл под настоящим именем всегда проверен, повторно хэш не считается (~3 с на large-v3-turbo).
- **Докачка:** при обрыве или отмене `.part` остаётся, следующий запуск просит `Range: bytes=N-`. Сервер ответил 200 — качаем заново, 416 — `.part` уже целый, решает хэш. Хэш не совпал — `.part` удаляется, ошибка просит запустить ещё раз.
- Тайм-аута на зависшее соединение нет (у ureq только общий тайм-аут тела, а модель качается минутами): отмена сработает, когда придёт следующий кусок или ОС оборвёт соединение.

## Распознавание (задачи 4.13–4.15, 2026-10-29)

- **Пока CPU.** Vulkan SDK не поставлен (docs/QUESTIONS.md), поэтому whisper-rs собирается без GPU-бэкенда. CMake 4.4.5 качает `cargo xtask deps` (хэш из официального `cmake-4.4.5-SHA-256.txt`), путь задан в `.cargo/config.toml` (`CMAKE`). В dev-профиле whisper.cpp собирается с `opt-level = 3`, иначе распознавание в десятки раз медленнее.
- **Скорость small на CPU:** 10 с синтезированной речи за 4,7 с (×2 реального времени), включая загрузку модели.
- **Качество:** синтезированная фраза из 16 слов (`fixtures/audio/tts-ru.flac`) распознана дословно; начала трёх предложений после вычета 0,26 с отстают или опережают настоящие на 0,07–0,16 с.
- **Редкая речь с длинными паузами** (фикстура владельца `speech.dcproj`: «раз… два… три» с паузами по 3–4 с на шумном микрофоне) — Whisper слышит «Разва три.», но DTW ставит все три слова в одну секунду. Это предел выравнивания Whisper на такой записи; длина слова ограничена 2 с, чтобы слово не растягивалось до конца сегмента.
- **Отмены распознавания нет.** `FullParams::set_abort_callback_safe` в whisper-rs 0.16 приводит данные колбэка к чужому типу; whisper.cpp получает «прервать» и падает с «failed to encode». Небезопасный обход в этом крейте запрещён (`unsafe` только в capture и encode). Для CLI отмена не нужна; для редактора — вопрос в docs/QUESTIONS.md.
- **Id слов и вырез по словам.** Слова каждой записи кэшируются в `cache/` в времени исходника; id `w1…` идут по порядку первых клипов записей, поэтому вырезы их не меняют. `cut w12-w20` переводит слова в выходное время, а каждая граница сдвигается к самому тихому окну 10 мс в пределах 150 мс.
