# 014. Размер и формат вывода CLI (задача 2.24)

Дата: 2026-10-28. Снимок: `crates/cli/src/snapshots/dc_cli__e2e_tests__scenario_output_is_short_and_readable.snap`, тест `crates/cli/src/e2e_tests.rs`.

## Сценарий

Проект из двух клипов (20 и 10 с) в папке «Урок 2.devcast»; 17 команд: info, ls clips, cut с `--dry-run` и без, zoom add ×2, ls zooms, clip split, apply плана из 5 шагов с `--dry-run` и без, ls clips, опечатка в команде (код 2), ненайденный id (код 1), undo, redo, history, info.

## Замер

**Это оценка, а не подсчёт токенизатором.** Считается только то, что команды печатают (stdout + stderr), без самих команд.

| Что | Строк | Символов | Байт UTF-8 | Токенов (оценка) |
|---|---|---|---|---|
| Вывод сценария, 17 команд | 28 | 1920 | 2431 | ≈ 500–600 (символы/4 … байты/4) |
| В среднем на команду | 1,6 | 113 | 143 | ≈ 30–35 |
| `skill/SKILL.md` | — | 3543 | 5071 | ≈ 900–1300 |
| `devcast help --json` | — | — | 23968 | ≈ 6000 |

Кириллица в выводе — 455 символов из 1920; на ней токенизатор тратит больше, поэтому верхняя граница считается по байтам.

## Решения

- Ответ на правку — одна строка diff; ошибки — одна строка с подсказкой. Весь сценарий читается без кода (см. снимок).
- В `ls` вложенный объект печатается полями через точку (`focus.x=0.5  focus.y=0.5`), а не JSON в тексте. `--json` не изменился.
- В `history` номера шагов выровнены по правому краю: с 10 шагов колонка команд не съезжает.
- `help --json` дорогой (≈ 6000 токенов): в skill он упомянут только для схем, обычно хватает `help <команда>`.
