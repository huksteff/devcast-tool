# 000. Ответы на вопросы из выжимок v1

Дата: 2026-10-27. Вопросы собраны из разделов «Вопросы владельцу» в `docs/porting/*.md`.
- **Владелец** — ответил владелец.
- **По умолчанию** — решение агента по рекомендации. Владелец может изменить любое; тогда правим этот файл и SCOPE.

## Ответы владельца

| Тема | Решение |
|---|---|
| Картинки курсоров | Наборы v1 macOS/Windows 11 (копии чужих курсоров) **не берём**. Наборы: «Системный» (картинки, записанные при захвате; по умолчанию), свой нарисованный набор под нашей лицензией, загрузка своей картинки. |
| Кисть | Shift+ЛКМ — ластик. Alt+ЛКМ — прямая линия. |
| Кривая плавности зума | Вместо 5 кривых — один ползунок «Плавность камеры» (от «резко» до «мягко»), он меняет пружину камеры поверх пресетов Focused/Smooth. |
| Ускоренные участки | Анимации аннотаций, печать облачка, эффекты кликов и анимации субтитров идут с нормальной скоростью (по времени выхода). Ускоряется только запись под ними. |

## Решения по умолчанию

**Время и координаты**
- Эффекты привязаны ко времени исходника. Длительности анимаций считаются по времени выхода (см. ответ про ускорение).
- Кейфреймы хранятся относительно начала аннотации и едут вместе с ней. В v1 время было абсолютным — это баг, не переносим.
- Координаты аннотаций и фокуса зума задаются в кадре проекта (до трансформа камеры). Аннотации движутся и масштабируются вместе с камерой, как в v1.

**Аннотации**
- Толщина обводки и стрелки задаётся отдельно и не зависит от размера фигуры.
- Blur: тонировка с прозрачностью 0–100% (0 — чистое размытие, 100% — сплошная «цензура»). Радиус углов — в «Тонкой настройке», по умолчанию 8.
- slide называется по стороне появления: «слева», «справа», «сверху», «снизу». На выходе движение продолжается, как в v1: въехал слева — уехал вправо (решение владельца 2026-11-02).
- Встроенные шрифты (OFL, с кириллицей, лежат в программе): Inter (по умолчанию), Montserrat, Roboto, PT Serif, JetBrains Mono. Набор общий для аннотаций и субтитров.
- Градиент бывает статичным или анимированным, направление задаётся. Свечение работает и без градиента.
- draw-in есть у фигур и рисунков. Прямоугольник получает радиус углов.
- Порядок слоёв: субтитры всегда поверх аннотаций, одинаково в превью и экспорте.
- Картинки: PNG, JPG, WebP и GIF (анимированный GIF проигрывается). SVG не поддерживается — только растр (решение владельца 2026-11-02).

**Субтитры**
- Цвета слов: ещё не произнесённые — «неактивный», уже произнесённые — основной, текущее — цвет подсветки.
- При нескольких строках на странице всё равно одна реплика.
- Размер шрифта задаётся «в пикселях при 1080p» и масштабируется только с разрешением выхода, а не с шириной блока.
- Русские сокращения («т.е.», «т.д.», «т.к.», «и т.п.», «др.») не рвут реплику.
- При правке текста неизменённые слова сохраняют тайминги, новые равномерно делят промежуток.
- Несколько дорожек распознаются по отдельности и сливаются по времени; при перекрытии приоритет у микрофона.

**Звук**
- Нормализация EBU R128: −16 LUFS, true peak −1 dBTP.
- На стыках вырезов — микрокроссфейд 10 мс без щелчков.
- Mute есть и для каждого канала клипа, и для клипа целиком. Общего уровня клипа нет.
- Клип берёт уровни по умолчанию, пока их не изменили. Изменённый параметр клипа становится своим.
- Дополнительные аудиодорожки стоят по времени выхода и не сдвигаются при нарезке.
- Declip не делаем: запись чистая, шумоподавление включается по желанию и только у микрофона (`mic`; владелец 2026-10-31): `audio channel` не включает его у других дорожек, а включённое в старых проектах у них микс не применяет.
- `devcast silences`: по умолчанию −30 dB и 0,5 с (проверено в v1), по дорожке микрофона. Уточнение при задаче 4.11: громкость меряется по RMS окон 50 мс, а не по каждому сэмплу, как `silencedetect` в v1. На записи владельца с поднятым усилением микрофона шум (−33…−38 dB RMS) даёт одиночные сэмплы громче −30 dB, и по сэмплам пауз не находилось вовсе. **Решение владельца 2026-11-03:** порог не постоянный, а из самой дорожки — посередине в dB между шумом (10-й процентиль уровней блоков 50 мс, цифровая тишина считается −90 dBFS) и речью (97-й процентиль): у тихого микрофона (речь −35…−41 dBFS) −30 dB давал тишину почти на всю запись, и субтитры теряли слова. «Речь − 15 dB» отклонено: на шумном микрофоне (шум −45, речь −35) такой порог ниже шума и пауз нет. `--db` у `devcast silences` задаёт свой порог (`dc_audio::silence::threshold`); для субтитров свой порог хранится в проекте — `captions style --silence <dB|auto>`.

**Зум**
- Автозумы — по кластерам кликов, как фактически работало в v1. Паузы курсора в v1 давали шум и были отключены.
- Условие «формат ≥ 1.2» убираем: вертикальных форматов нет.
- Пресеты движения не меняют размер курсора.
- Рамка на превью есть и у зумов в режиме слежения (задаёт масштаб).
- Масштаб по умолчанию 1,5×.
- Зум-выход всегда успевает закончиться до конца видео.
- Одна модель камеры: детерминированная пружина (трек камеры считается с фиксированным шагом и кэшируется). «Classic Animation» не переносим.

**Курсор и клики**
- Размер эффектов клика и облачка считается от видимой высоты курсора.
- Сглаживание использует пружину текущего пресета движения.
- Типы курсора своего набора: стрелка, I-beam, рука, 4 ресайза, перемещение, «нельзя», ожидание.
- Loop: заменяются только последние 670 мс (возврат в начальную точку), время не растягивается.
- Облачко у края кадра перескакивает на другую сторону курсора. Градиент плавный, свечение настоящее (общий код с аннотациями).
- Sway 0–2. Частиц во «вспышке» 18.
- Своя картинка курсора: «горячая точка» задаётся кликом в диалоге, по умолчанию левый верхний угол.

**Редактор и HUD**
- Ctrl+V вставляет в позицию указателя.
- `[` / `]` — предыдущий/следующий ключ выбранной аннотации; без выбора — ±5 с.
- При воспроизведении таймлайн прокручивается за указателем.
- Мультивыделение: Ctrl+клик и рамка.
- Удаление клипа без подтверждения (есть undo).
- На HUD есть значок состояния системного звука.
- Обратный отсчёт показывается на записываемом мониторе.
