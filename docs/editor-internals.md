# Редактор изнутри (dc-app)

Подробности устройства редактора `crates/app/src/editor/`. Инварианты крейта — в `crates/app/CLAUDE.md`.

- Состояние окна без истории — `View` (выбор `selection.rs`, участок, жесты, вид таймлайна `timeline::Viewport`); `View::keep` после правки выбрасывает пропавшее. Время ↔ x — `TimeScale`. Окно таймлайна (`timeline_window.rs`, «↗») — тот же `EditorWindow`, своё только `Viewport` (скрытый ждёт в `View::parked`); встроенный таймлайн при нём скрыт; кадр, изменивший общее (`EditorWindow::mark`), помечает другое окно и будит главное, оно перерисовывает помеченное.
- Таймлайн (`timeline/`): главная дорожка — команды fx/cut (`montage.rs`, время — секунды с шестью знаками, как `devcast`); перетаскивание регионов — команды `editor/regions.rs`, прилипание — `snap.rs`, строки — `rows.rs`. Волна — поток `devcast-peaks` (`waves.rs`, кэш в `cache/`), нажатия — поток `devcast-presses` (`presses.rs`). Неподвижная мышь ничего не просит (иначе вечная перерисовка).
- Инспектор (`inspector/`): правка — одна команда; ползунок и цвет — черновик до отпускания, поле числа — по Enter или потере фокуса, текст — до Enter или клика мимо (`rows::flush`). Ключи аннотаций — как в CLI: `--at` только когда указатель на ключе, с «Авто-ключами» (`View::auto_keys`, по умолчанию выкл, v1) — `--at` указателя (`inspector::target`, общий с превью). I — `keyframes.rs`, копия ключа — `clipboard.rs` (`annot key copy`), подсказка маркера — `timeline/key_tip.rs`. Шрифт — `inspector/font.rs`: встроенные и шрифты проекта (`EditorWindow::fonts`), «Добавить шрифт…» — `Action::Font` (`dc_ops::import_font` + команда панели). Дорожки `audio-N` импортированного видео для панели звука клипа читает поток `devcast-streams` (`streams.rs`).
- Превью (`preview/`): кадр рисует поток `devcast-preview` путём `devcast frame` и экспорта (`Evaluator`, `Compositor::draw`) в текстуру общего устройства, берётся только новейший запрос. Правка на превью (`stage/`) — черновик `Document::draft` без истории, отпускание — одна команда; кисть рисунка — `stage/brush.rs` (ЛКМ — инструмент панели кисти `View::brush`, Shift ластик размера `View::eraser`, Alt прямая, ПКМ двигает), штрих — `drawing add`.
- Воспроизведение (`playback/`): часы — сыгранное устройством звука (`dc_audio::Line::heard`), без звука — `Instant`; звук — поток `devcast-sound` с миксом экспорта.
- Клавиши редактора: таблица `keymap.rs` — единственный источник для обработки, справки, подсказок и настроек; `None` в `keys::act` — функция ещё не готова. Пока открыто поле ввода, кроп или вопрос закрытия, клавиши молчат; при справке работает только её клавиша.
