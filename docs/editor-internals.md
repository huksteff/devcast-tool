# Редактор изнутри (dc-app)

Подробности устройства редактора `crates/app/src/editor/`. Инварианты крейта — в `crates/app/CLAUDE.md`.

- Состояние окна без истории — `View` (выбор `selection.rs`, участок, жесты, вид таймлайна `timeline::Viewport`); `View::keep` после правки выбрасывает пропавшее. Время ↔ x — `TimeScale`. Окно таймлайна (`timeline_window.rs`, «↗») — тот же `EditorWindow`, своё только `Viewport` (скрытый ждёт в `View::parked`); встроенный таймлайн при нём скрыт; кадр, изменивший общее (`EditorWindow::mark`), помечает другое окно и будит главное, оно перерисовывает помеченное.
- Таймлайн (`timeline/`): главная дорожка — команды fx/cut (`editor/montage.rs`, время — секунды с шестью знаками, как `devcast`); дорожки эффектов — `dc_fx_*::lane` через регистрацию `editor/lanes.rs` (ARCHITECTURE «Дорожка эффекта»); перетаскивание регионов — команды дорожки эффекта (`editor/regions.rs`), прилипание — `timeline/snap.rs`, строки — `editor/rows.rs`. Волна — поток `devcast-peaks` (`waves.rs`, кэш в `cache/`), нажатия — поток `devcast-presses` (`presses.rs`). Неподвижная мышь ничего не просит (иначе вечная перерисовка).
- Инспектор (`inspector/`): набор панели — `dc_ui_kit::panel`, все панели живут в своих эффектах и получают `Cx::base` и свои факты (ARCHITECTURE «Панель эффекта», задача 7.35); аннотация — `dc_fx_annotations::panel` с разделом вида (`Section` в `fx/text` и др.), вид выбирает `object.rs`. Правка — одна команда; ползунок и цвет — черновик до отпускания: пока их держат, превью показывает его (`rows::drafting` → `Document::draft`, `View::panel_draft`), отпускание — одна команда; поле числа — по Enter или потере фокуса, текст — до Enter или клика мимо (`rows::flush`). Ключи аннотаций — как в CLI: `--at` только когда указатель на ключе, с «Авто-ключами» (`View::auto_keys`, по умолчанию выкл, v1) — `--at` указателя (`dc_fx_annotations::panel::target`, общий с превью). I — `keyframes.rs`, копия ключа — `clipboard.rs` (`annot key copy`), подсказка маркера — `timeline/key_tip.rs`. Шрифт — `dc_ui_kit::panel::Cx::font`: встроенные и шрифты проекта (`EditorWindow::fonts`), «Добавить шрифт…» — `Request::AddFont` → `Action::Font` (`dc_ops::import_font` + команда панели); «Заменить…» картинки — `Request::Picture` → `Action::Picture`. Дорожки `audio-N` импортированного видео для панели звука клипа читает поток `devcast-streams` (`streams.rs`).
- Превью (`preview/`): кадр рисует поток `devcast-preview` путём `devcast frame` и экспорта (`Evaluator`, `Compositor::draw`) в текстуру общего устройства, берётся только новейший запрос. Правка на превью (`stage/`) — черновик `Document::draft` без истории, отпускание — одна команда; жесты эффектов — таблица `lanes::STAGES` (`dc_ui_kit::stage::Stage`: рамка зума, кисть рисунка, боксы аннотаций — в этом порядке, первый взявший указатель (`Answer::ours`) его забирает), у редактора — `Cx` (проект, выбранное, регионы показанных строк, указатель, привязка), жест в `View::stage` (`Held`), выбор окна в `View::kept`, черновик, выбор (`Answer::pick`) и конец жеста; картинку без камеры просит `Stage::bare`; двойной клик по тексту отдаёт клавиши его полю на панели, весь текст выделен (`rows::focus_text`); кисть рисунка — `dc_fx_drawing::stage::Strokes` (ЛКМ — инструмент панели кисти, Shift ластик её размера, Alt прямая, ПКМ двигает), штрих — `drawing add`.
- Воспроизведение (`playback/`): часы — сыгранное устройством звука (`dc_audio::Line::heard`), без звука — `Instant`; звук — поток `devcast-sound` с миксом экспорта. Во время игры указатель двигает кадр каждого окна сам (`playback::advance`, `keep_playing`): свёрнутое окно кадров не получает, а другое играет дальше; поэтому `mark` при игре указатель не сравнивает.
- Клавиши редактора: таблица `crates/app/src/keymap.rs` — единственный источник для обработки, справки, подсказок и настроек; `None` в `keys::act` — функция ещё не готова. Пока открыто поле ввода, кроп или вопрос закрытия, клавиши молчат; при справке работает только её клавиша.
- Производительность (7.34): замеры — `preview/speed_tests.rs` (поток превью: 720p, 1080p, 4K) и `ui_speed_tests.rs` (кадр UI с 500 регионами, бюджет 8 мс в release), запуск `cargo nextest run -p dc-app --release --run-ignored only -E 'test(ui_speed) | test(playback_speed)' --no-capture`; покой без кадров — обычный тест `idle_tests.rs` (наблюдатель запросов перерисовки egui). В живом окне каждый нарисованный кадр превью — строка журнала `preview frame drawn` с его временем (`RUST_LOG=info,dc_app::editor::preview::worker=debug`): по шагам времени видны пропуски.
