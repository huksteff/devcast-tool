# Монтаж с Codex

DevCast запускает Codex CLI из своей вкладки «Нейронка». Подойдёт отдельный CLI или CLI, который поставляется с Codex Desktop на Windows. DevCast ищет его в `PATH`, `~/.local/bin`, `%APPDATA%/npm` и `%LOCALAPPDATA%/OpenAI/Codex/bin`, выбирает самую новую найденную версию. Отдельные ключи в DevCast вводить не нужно.

## Из редактора

1. Открой проект и вкладку «Нейронка».
2. Если найдены оба агента, выбери **Codex** в группе «Нейронка». Выбрать его можно и тогда, когда Claude не вошёл в аккаунт.
3. Если нужен вход, нажми «Войти», заверши его в браузере и нажми «Проверить снова».
4. В списке моделей оставь «По умолчанию», чтобы Codex выбрал модель из своих настроек, или выбери модель из каталога установленного CLI. Каталог загружается в фоне; ранее заданная модель сохраняется в списке. «Проверить снова» обновляет каталог.
5. Отметь рецепты или напиши просьбу и нажми «Сделать красиво».

Во время работы видны команды и сообщения Codex, после неё — ответ и расход токенов. «Доделать или исправить» продолжает тот же разговор. «Остановить» завершает процесс и его дочерние команды. Весь монтаж одного запуска — один шаг отмены. При переключении между Claude и Codex разговор начинается заново, модель сбрасывается на умолчание нового агента.

Codex получает единственный клиентский инструмент devcast: массив аргументов CLI без имени программы. Общая оболочка, просмотр файлов и сторонние инструменты отключены; модель работает read-only, запросы дополнительных разрешений запрещены. DevCast проверяет настройки до первого запроса к модели и запускает только свой devcast.exe с фиксированными проектом и группой отмены. Аргументы передаются как argv, без разбора оболочкой. Правки идут существующими CLI, реестром и IPC; запуск и продолжение — отдельные шаги отмены. Нужен Codex CLI со штатным app-server и dynamicTools; конфигурация пользователя на диске не меняется. Подробности — [решение 021](decisions/021-codex-transport.md).

## Из командной строки

```powershell
devcast recipes agent codex
devcast recipes login
devcast recipes model default
devcast --project "D:\Видео\Урок.devcast" beautify --ask "Убери паузы и добавь зумы"
```

Для одного запуска: `devcast beautify --agent codex --ask "Добавь зумы"`. Модель другого агента при таком выборе не наследуется; `--model` задаёт её явно. Для продолжения передай `--resume` с идентификатором сессии из ответа. Если выбранный агент не найден, DevCast сообщит об этом; автоматически другой агент выбирается только при `devcast recipes agent auto`.

## Монтировать прямо из Codex

```powershell
devcast skill install --agent codex
```

Команда устанавливает инструкции в `~/.agents/skills/devcast/SKILL.md`, где их находят Codex CLI и Desktop. В Codex попроси: «Используй $devcast и добавь зумы в проект D:\Видео\Урок.devcast». Папка установленного DevCast должна быть доступна через `PATH`, либо укажи полный путь к `devcast.exe`.

Ограничение «только devcast» относится к запуску из DevCast. У внешнего Codex, которому поставлен только скилл, остаются собственные инструменты и разрешения: скилл сам по себе не является ограничителем.

`devcast skill install` без параметров сохраняет прежнее поведение: установка для Claude Code. `devcast skill files` готовит инструкции для любых агентов.

Протокол запуска и входа: [официальная документация Codex CLI](https://developers.openai.com/codex/cli/reference), [app-server](https://developers.openai.com/codex/app-server), [папки скиллов](https://developers.openai.com/codex/skills).
