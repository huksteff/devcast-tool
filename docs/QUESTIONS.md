## Открытые вопросы

- **Фигуры (5.33).** 1) draw-in как в After Effects/DaVinci: контур прорисовывается по длине, заливка проявляется — подходит? 2) Концы стрелки задаются в долях бокса (едут с боксом и анимациями); добавить ли ввод сразу в долях кадра? 3) Подсветка при смене фигуры сама получает свой вид (заливка 28 %, без обводки) — оставить или одинаковые поля у всех? 4) Толщина по умолчанию 6, голова стрелки `min(0,354·L, 5,3·толщины)` — устраивает? 5) У `annot set` флаги `--from/--to` — время, у `shape set` — точки фигуры; рекомендую переименовать точки в `--tail/--tip`.
- **Ключи аннотаций.** 1) Время ключей — по кадрам записи (от начала аннотации): на ускоренном участке движение по ключам ускоряется вместе с видео, вырез не сдвигает ключи относительно картинки. Альтернатива — по готовому видео, как длительности анимаций. 2) Правка без `--at` при наличии ключей пишет значение во все ключи (удобно поправить опечатку везде); альтернатива — ошибка с требованием `--at`. Сейчас сделано первое в обоих пунктах.
- **Выход slide.** Сделано «вход наоборот»: `slide_left` въезжает слева и уезжает влево (одинаково для всех анимаций, имя значит одну сторону). В v1 выход продолжал движение (въехал слева — уехал вправо). Поменять — одна строка в `fx/annotations/src/motion.rs`.
- **Свои шрифты (.ttf/.otf).** SCOPE обещает свои шрифты, копируемые в проект. Сейчас аннотация принимает любое имя семейства, но команды, которая кладёт файл шрифта в `assets/`, нет, а экспорт и `frame` грузят только встроенные. Варианты: 1) отдельная задача — `devcast font add <файл>` + загрузка `assets/` проекта в экспорте, `frame` и приложении (общая для аннотаций и субтитров) — рекомендую; 2) сделать сразу; 3) оставить только встроенные. До решения фича `annot.text` остаётся `todo`.
- **Аннотации над курсором или под ним?** Сейчас порядок кадра: видео → аннотации → курсор и облачко → субтитры и клавиши. В экспорте v1 аннотации были над курсором; решение 000 говорит только «субтитры поверх аннотаций». Рекомендую оставить аннотации под курсором: курсор не прячется под плашкой. Пока так и делаю, переставить — одна строка в рендере.
- **Фикстура речи.** В `speech.dcproj` записано «раз… два… три» с паузами по 3–4 с на очень тихом шумном микрофоне: Whisper слышит слова, но время слов на такой записи не выравнивает (решение 010). Для проверки субтитров нужна обычная речь 15–20 с. Перезапишите, пожалуйста, по `fixtures/recordings/README.md` (говорить связно, с короткими паузами), при желании с микрофона поближе.
