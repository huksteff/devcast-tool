## Открытые вопросы

- **Субтитры после выреза слова (2026-11-04).** Вырезанное слово остаётся в тексте реплики: субтитры хранят слова записи, нарезка их не трогает. Сейчас `captions gen` (и «Пересоздать» в редакторе) берёт только слова, оставшиеся в видео, а нейронке сказано делать субтитры после вырезов. Но если вырезать слово, когда субтитры уже есть, оно остаётся на экране. Варианты: (а) так и оставить, пересоздавать вручную; (б) отрисовка сама не показывает вырезанные слова (раскладка строк зависит от нарезки, пересчёт при каждом вырезе); (в) вырез слова в редакторе предлагает «Обновить субтитры». Рекомендую (б).

- **Фикстура речи (записана 2026-11-03).** Ваша запись легла второй фикстурой `fixtures/recordings/speech_owner.devcast`; старая `speech.devcast` осталась для тестов шумоподавления и пауз. В видео записи — весь основной экран (окна Fork, Claude): это попадёт в git (LFS). Если не хотите хранить экран, скажите — заменю видео на чёрный кадр той же длины, звук останется.
- **Ручные проверки:** переключить устройство вывода звука во время записи (запись не должна оборваться); дать послушать нормализованный и очищенный от шума звук в экспорте.
- **Старые записи `.dcproj` (ночь 2026-11-03).** Ваши записи в «ВидеоDevCast» лежат в папках `recording-N.dcproj`, поэтому библиотека и `devcast ls projects` их не видят (решено: старые папки переименовать вручную). Варианты: (а) оставить так; (б) библиотека показывает строку «Найдено 4 старые записи .dcproj — переименовать?» и переименовывает по кнопке; (в) `devcast` и программа сами переименовывают при запуске. Рекомендую (б).
- **Оценка размера в экспорте.** «≈ 85 МБ» считается по таблице бит на пиксель, подобранной под пример макета, а не по замерам. Варианты: (а) оставить как прикидку со значком «?»; (б) убрать оценку; (в) после нескольких настоящих экспортов подобрать таблицу по факту. Рекомендую (в).
- **Окно таймлайна в первый раз (ночь).** Теперь оно открывается на другом мониторе (как второй экран DaVinci), при одном мониторе — у нижнего края. Дальше запоминается, куда вы его поставили. Подходит?
- **Скачивание модели из CLI и программы одновременно** писало бы один файл `.part` двумя процессами. Варианты: (а) CLI скачивает через программу, когда она запущена; (б) межпроцессная блокировка файла. Рекомендую (а).
