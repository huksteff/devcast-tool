# Editable application configuration

- `contacts.yaml` — repository URL and contacts. Keep `Eng` and `Ru` sections in sync.
- `Changelog.md` — entries shown in the in-app **What's new** window. Use `## version`, `### section`, and `- item`.
- `i18n.ts` — supported UI languages and the default language.
- `locales/` — translation files grouped by language and namespace.
