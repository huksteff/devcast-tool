# dc-fx-captions (`fx/captions`)

Эффект «Субтитры»: реплики со словами, команды правки, текст для перевода (5.27), стиль и отрисовка (5.28).

## Инварианты

- Состояние `CaptionsState` в `project.effects["captions"]`: `cues` (отсортированы по записи и началу, могут перекрываться), счётчик `ids` (`s<число>`, номера не повторяются).
- Реплика принадлежит записи: `media` (`Media.path`) + `range` в её source time; слова — тоже source time. Нарезка и скорость их не трогают.
- `Cue::check`: длительность > 0, хотя бы одно слово, слова по порядку без нахлёстов внутри `range`, без пробелов. Длительность слова может быть 0 (так их даёт Whisper). Текст реплики — слова через пробел, отдельно не хранится.
- Время в аргументах — время готового видео (`TimeArg<Output>`); перевод в source только через `TimeMap` (`span.rs`), граница должна попасть в клип записи реплики.
- Правка текста (`retime::retext`, решение 000): слова, найденные без изменений (наибольшая общая подпоследовательность), сохраняют время, новые поровну делят промежуток между ними. Новые границы растягивают слова линейно (`rescale`, выжимка §9).
- `captions paste --item <JSON реплики> --at --duration` (буфер редактора, 7.9) — копия с новым id в записи, которая идёт в `at`; слова растягиваются с ней (`rescale`), конец должен попасть в ту же запись.
- `split` — в паузе между словами, ближайшей к моменту; `merge` — со следующей репликой той же записи (нахлёст слов — ошибка).
- `CaptionsGen` и `CaptionsImport` — не команды реестра (Whisper, файлы): Gen собирает `speech::generate` dc-cli для CLI и процесса распознавания редактора (решение 018) (`NewCue` — ещё и JSON: так его шлёт процесс распознавания редактора), Import — CLI. Gen заменяет все реплики; `merge_tracks` — дорожки по приоритету, слова поздней, перекрытые словами ранней, выбрасываются.
- Текст для перевода (`text.rs`): строка `<id> <текст>` на реплику, по выходному времени, вырезанные в конце; импорт меняет только текст перечисленных реплик. SRT/VTT не делаем (SCOPE).
- Команда без реальных изменений возвращает пустой `Diff`. Зависит только от dc-core и dc-render (позже dc-ui-kit).
- Стиль (`style.rs`, `captions style`): `settings` состояния (поле `SETTINGS_FIELD`): показ (по умолчанию да — реплик нет до `captions gen`), встроенный шрифт (`dc_render::FAMILIES`), размер в px при короткой стороне 1080 (растёт только с разрешением выхода, решение 000), цвета сказанных, текущего (по умолчанию жёлтый) и несказанных слов, тень, строки 1–4, отступ снизу %, ширина %, радиус и прозрачность чёрной плашки, анимация none/fade/rise/pop. Остальные значения по умолчанию — v1.
- Раскладка (`layout.rs`, решение 016): `Prepared::new(state, canvas, &mut TextMeasure)` один раз — ширины слов настоящими шрифтами, строки DP v1 (§6.2) только внутри реплики, страницы по `rows` строк поровну внутри реплики (решение 000); первая страница с начала реплики, следующие — с первого слова, последняя — до конца реплики.
- Кадр (`evaluate.rs`, §6.4–§8): реплика записи на экране с `start ≤ now`, при зазоре до следующей < 500 мс держится до неё; страница — последняя начавшаяся; слова до текущего — `color`, текущее (последнее начавшееся, до первого — первое) — `highlight`, дальше — `inactive`. Вход и выход 180 мс по времени выхода (`output_span`); страница, за которой нет близкой реплики, уходит в ноль к концу своих слов. Сдвиг rise/pop (18/8) и радиус заданы при размере 30 и растут со шрифтом. Плашка — `Shapes` (скругление), текст — `Text` по центру, оба в `Band::Overlay` до клавиш.

## Как тестировать

- `cargo nextest run -p dc-fx-captions`: команды на синтетических проектах (вырезы, скорость, две записи, undo/redo), `retime_tests.rs` — время слов, `layout_tests.rs` — DP строк, страницы внутри реплики (шрифты `.deps/fonts`), `evaluate_tests.rs` — цвета слов, когда видна, место плашки, вход и выход, rise.
- CLI на настоящей речи — `crates/cli/src/captions_tests.rs`.

## Куда не лезть

- Распознавание и разбиение на реплики — `dc-transcribe`; путь `captions gen` — `dc-cli` (`speech.rs`); команды `captions gen/export/import` — `dc-cli` (`captions.rs`), кнопка редактора — `dc-app`.
