# dc-fx-crop (`fx/crop`)

Эффект: кроп каждого клипа и формат выхода (free, source, 16:9, 16:10, 4:3). Пока только модель и команды `crop`, `aspect`.

## Инварианты

- Зависит только от dc-core, dc-render, dc-ui-kit (сейчас только dc-core).
- Состояние — `project.effects["crop"]`: `settings.aspect` (настройка, копируется в умолчания) и `clips` — кроп по `ClipId`.
- Кроп — `Rect` в долях кадра исходника клипа: внутри 0..1, ширина и высота ≥ `MIN_SIZE` (0.05). Весь кадр = записи нет.
- Кроп удалённого клипа остаётся в состоянии: id не переиспользуются, undo удаления возвращает клип с кропом.
- `aspect` не меняет кропы: клип с другим соотношением сторон вписывается в кадр выхода с чёрными полями (рендер).
- Вертикальных форматов нет.

## Как тестировать

- `cargo nextest run -p dc-fx-crop`: команды, границы кадра, минимальный размер, ненайденный клип, undo → redo, разбор JSON-аргументов, правила реестра.
