# dc-fx-zoom (`fx/zoom`)

Эффект «Зум»: регионы зума, режим follow/fixed, настройки движения камеры. Пока только модель и команды (2.22); evaluate/draw, слежение и автозумы — задачи 4.17, 5.17–5.19.

## Инварианты

- Состояние `ZoomState` в `project.effects["zoom"]`: `zooms`, счётчик `ids` (`z<число>`, номера не повторяются), `settings` (поле `SETTINGS_FIELD`).
- Зум принадлежит одному клипу: `clip` + `range` в source time этого клипа. Через стык клипов зум не переходит.
- Время в аргументах команд — секунды готового видео; перевод в source только через `TimeMap` (`span.rs`).
- Зумы одного клипа не перекрываются (касаться можно). Масштаб 1–5, по умолчанию 1,5. Фокус — точка кадра проекта 0..1.
- Пресет = длительности входа и выхода (Focused 200/200 мс, Smooth 1522,575/1015,05 мс). Активный пресет определяется равенством длительностей. Плавность, blur и склейка от пресета не зависят.
- Команда без реальных изменений возвращает пустой `Diff`.
- Зависит только от dc-core (позже dc-render, dc-ui-kit).

## Как тестировать

- `cargo nextest run -p dc-fx-zoom`: команды на синтетических проектах (вырезы, скорость, несколько клипов, undo/redo).

## Куда не лезть

- Регистрация команд в CLI — `dc-cli` / `dc-ops` (`ops()` и `effect()` отсюда).
- Курсор и его пружина — `fx/cursor`: пресеты зума курсор не трогают.
