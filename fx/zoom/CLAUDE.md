# dc-fx-zoom (`fx/zoom`)

Эффект «Зум»: регионы зума, режим follow/fixed, настройки движения камеры, автозумы (4.17). Пока без evaluate/draw и слежения — задачи 5.17–5.19.

## Инварианты

- Состояние `ZoomState` в `project.effects["zoom"]`: `zooms`, счётчик `ids` (`z<число>`, номера не повторяются), `settings` (поле `SETTINGS_FIELD`).
- Зум принадлежит записи: `media` (`Media.path`) + `range` в её source time. Разрезание и перестановка клипов его не трогают. Через стык клипов разных записей зум не переходит.
- Время в аргументах команд — время готового видео (`TimeArg<Output>`, длительность — секунды); перевод в source только через `TimeMap` (`span.rs`).
- Зумы одной записи не перекрываются (касаться можно). Масштаб 1–5, по умолчанию 1,5. Фокус — точка кадра проекта 0..1.
- Пресет = длительности входа и выхода (Focused 200/200 мс, Smooth 1522,575/1015,05 мс). Активный пресет определяется равенством длительностей. Плавность, blur и склейка от пресета не зависят.
- Команда без реальных изменений возвращает пустой `Diff`.
- Автозумы (`suggest.rs`, выжимка §10, решение 000 — только клики): телеметрию передаёт вызывающий (`Recording`: указатель в source time, точки в долях кадра записи). Нажатия на выходе (вырезанные и вне кадра клипа после кропа — `hidden`) → группы по `CLUSTER_GAP` 2,5 с в пределах одного клипа → зум `[первый − 0,5 с, последний + 0,5 с]` в границах клипа; фокус — самый «сильный» клик по `classify.rs` (§10.2), при равенстве ранний; группа, задевающая существующий зум, пропускается (`taken`). Ставится через `Suggestion::command` → обычный `ZoomAdd`. `settings.auto` — автозумы сразу после записи (по умолчанию да).
- Зависит только от dc-core (позже dc-render, dc-ui-kit).

## Как тестировать

- `cargo nextest run -p dc-fx-zoom`: команды на синтетических проектах (вырезы, скорость, несколько клипов, undo/redo); автозумы — `suggest_tests.rs` на синтетических нажатиях.

## Куда не лезть

- Регистрация команд в CLI — `dc-cli` / `dc-ops` (`ops()` и `effect()` отсюда).
- Курсор и его пружина — `fx/cursor`: пресеты зума курсор не трогают.
