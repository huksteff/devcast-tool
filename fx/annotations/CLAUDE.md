# dc-fx-annotations (`fx/annotations`)

Общее для аннотаций: модель (время, дорожки, слои, бокс, поворот) и команды `annot add|set|move|layer|rm` (5.29), анимации входа и выхода, `annot anim` (5.30). Дальше здесь же кейфреймы (5.31).

## Инварианты

- Зависит от dc-core и dc-render (позже dc-ui-kit). Виды аннотаций (`fx/text`, `shape`, `image`, `drawing`, `blur`) зависят от этого крейта, а не наоборот.
- Состояние `AnnotationsState` в `project.effects["annotations"]`: `annotations`, счётчик `ids` (`a<число>`, номера не повторяются). Список `ls annots`.
- Аннотация: `kind`, `media` + `range` в source time записи (показ `start <= t < end`), `track` 0..`TRACKS`, `rect` — бокс в долях кадра проекта до камеры (едет с камерой, решение 000), `rotation` — градусы по часовой вокруг центра бокса, ±360.
- Поля вида лежат в `body` (JSON-объект) и принадлежат крейту вида: он читает и пишет их через `Annotation::body`/`set_body`, недостающие поля — значения по умолчанию его типа. Новый вид не меняет этот крейт: имена видов (`Kind`) заданы здесь.
- Порядок отрисовки (`shown_at`): по дорожке снизу вверх, внутри дорожки по порядку в `annotations`. Перекрытие по времени разрешено везде.
- `Placement::of(annotation, canvas)` — бокс в px холста до камеры, поворот, `k` (px холста на px при короткой стороне 1080, `REFERENCE`), `opacity` и `reveal` (доля показанного: буквы печати, длина пути draw-in): из него рисуют все виды. `Placement::at(…, map, now, t)` — с анимацией кадра (`Pose`). Ключи (5.31) тоже будут менять `Placement`, а не виды. Рисует аннотации `dc_ops` (`annotations.rs`): вид → слой в `Band::Annotations`.
- Анимации (`motion.rs`, выжимка §3): `enter`/`exit` — `Stage` (анимация + длительность), по умолчанию `none` и 0,3 с, в файл не пишутся, пока по умолчанию. Длительность — время выхода (решение 000): от первого показанного момента и до конца аннотации на готовом видео, ускорение не торопит, вырез не съедает. Применяется не длиннее показа, вход первым (зажим при расчёте кадра, а не в командах, поэтому вырезы и смена длины его не ломают). Выход — вход наоборот (slide_left уезжает влево, печать стирает с конца). Кривые v1: fade линейно, остальное smoothstep; pop `0.58+0.42e+0.14·sin(πe)` вокруг центра; slide 96/72 ref-px, сдвиг не масштабируется; typewriter и draw — `reveal` линейно. `Animation::fits`: typewriter только у текста, draw — у фигур и рисунков.
- Время в аргументах — время готового видео (`TimeArg<Output>`), перевод через `TimeMap` (`span.rs`). Аннотация лежит в одной записи, не короче `MIN_DURATION` (0,1 с) на выходе.
- `move --at` сохраняет длину на выходе; смена дорожки кладёт аннотацию сверху новой дорожки. `layer up|down` проходит мимо ближайшей аннотации той же дорожки, которая на экране одновременно; `top|bottom` — к краю дорожки.
- Команда без реальных изменений возвращает пустой `Diff`; ошибка не меняет проект.

## Как тестировать

- `cargo nextest run -p dc-fx-annotations`: `tests.rs` (add/set/rm, ошибки, время через вырез, 2× и вторую запись, undo/redo, файл проекта, поля вида, `ls`), `arrange_tests.rs` (порядок слоёв, `layer`, `move`), `motion_tests.rs` (кривые в ключевых точках, время через вырез и 2×, зажим длительностей, `Placement::posed`, `annot anim` и ошибки, запись в файл).

## Куда не лезть

- Отрисовка видов и их команды — в крейтах видов. Регистрация — `crates/cli/src/registry.rs`. Порядок эффектов в кадре — `dc_ops::Evaluator`.
