# dc-fx-annotations (`fx/annotations`)

Общее для аннотаций: модель (время, дорожки, слои, бокс, поворот) и команды `annot add|set|move|paste|layer|rm`, анимации входа и выхода (`annot anim`), ключевые кадры (`annot key add|rm|copy|move`).

## Инварианты

- Зависит от dc-core, dc-render и dc-ui-kit (панель). Виды аннотаций (`fx/text`, `shape`, `image`, `drawing`, `blur`) зависят от этого крейта, а не наоборот.
- Состояние `AnnotationsState` в `project.effects["annotations"]`: `annotations`, счётчик `ids` (`a<число>`, номера не повторяются). Список `ls annots`.
- Аннотация: `kind`, `media` + `range` в source time записи (показ `start <= t < end`), `track` 0..`TRACKS`, `rect` — бокс в долях кадра проекта до камеры (едет с камерой, решение 000), `rotation` — градусы по часовой вокруг центра бокса, ±360.
- Поля вида лежат в `body` (JSON-объект) и принадлежат крейту вида: он читает их через `Annotation::body`, команда `set` вида меняет через `edit_kind`. Новый вид не меняет этот крейт: имена видов (`Kind`) заданы здесь.
- Порядок отрисовки (`shown_at`): по дорожке снизу вверх, внутри дорожки по порядку в `annotations`. Перекрытие по времени разрешено.
- `Placement::of(annotation, canvas)` — бокс в px холста до камеры, поворот, `k` (px холста на ref-px, `dc_render::REFERENCE`), `opacity` и `reveal` (доля показанного, 0..1): из него рисуют все виды. `Placement::at(…)` — с анимацией кадра и ключами. Картинка — `look.rs` (шов `dc_render::look`): `shown_at`, `Placement::at`, поля между ключами; поля вида рисует его крейт (`look::Body`, `look::READ`), таблицу видов даёт регистрация `dc_ops`.
- Анимации (`motion.rs`): `enter`/`exit` — `Stage` (анимация + длительность), по умолчанию `none` и 0,3 с, в файл не пишутся, пока по умолчанию.
- Длительность анимации — время выхода (решение 000): ускорение не торопит, вырез не съедает. Зажим длительностей — при расчёте кадра, а не в командах.
- Выход — вход наоборот, кроме slide (движение продолжается); печать стирает с конца. Кривые — как в v1 (выжимка §3). `Animation::fits`: typewriter только у текста, draw — у фигур и рисунков.
- `shown_for` — время выхода от первого показанного момента (часы анимаций и кадров анимированных картинок).
- Ключи (`keys.rs`, выжимка §4): `Annotation::keys` — полный снимок `rect`, `rotation`, `body` на момент `at`. `at` — source time записи от начала аннотации: ключи едут с `move`, вырез и ускорение их не сдвигают. Ключи ближе `KEY_TOLERANCE` (1 мс) — один момент.
- Не ключуются время, дорожка, слой, анимации. До первого ключа — первый, после последнего — последний, между — smoothstep.
- Смешивание — трейт `Blend` (для `body` — `Blend for Value`, целые остаются целыми). Новый вид даёт `Blend` своему типу полей и сразу ключуется.
- Правка с ключами: `annot set --at` и `edit_body` пишут в ключ в этот момент; без `--at` поля меняются в аннотации и во всех ключах. Правка, совпавшая с показанным, ключей не создаёт. Время ключа в командах — `key_offset`.
- Время в аргументах — время готового видео (`TimeArg<Output>`), перевод через `TimeMap` (`span.rs`). Аннотация лежит в одной записи, не короче `MIN_DURATION` (0,1 с) на выходе.
- `move --at` и `paste` сохраняют длину на выходе; смена дорожки кладёт аннотацию сверху новой дорожки. `paste` — копия с новым id, ключи едут с ней.
- Команда без реальных изменений возвращает пустой `Diff`; ошибка не меняет проект.
- Панель (`panel.rs`, `panel_rows.rs`; ARCHITECTURE «Панель эффекта», «Аннотации»): строка ключа (‹ › — `Request::Seek`), «Основное» вида (трейт `panel::Section`, реализует крейт вида), «Вход и выход», «Дополнительно» (бокс в px кадра `Region::canvas`, поворот, время, дорожка, слой). Куда идёт правка — `Edit` (`--at` ключа у указателя, с «Авто-ключами» — указателя внутри аннотации: `panel::target`, им же правит превью); время, дорожка, слой и анимации — всегда без `--at`. Вид выбирает редактор (`panel::kind`), факты — `panel::Region`. `same_moment` — два времени выхода ближе `KEY_TOLERANCE`.
- Дорожка (`lane.rs`, `lane_tip.rs`; ARCHITECTURE «Дорожка эффекта»): строки по дорожкам `lane::rows` (регионы с именем вида и временами ключей на выходе, все ключи для [ и ]; сломанное состояние — `Rows::empty`), `LANE` (перенос — `annot move --at [--track]`, края — `annot set`, копия — `annot paste`, «Дублировать» — сразу после себя на свободной строке), новая — `lane::added` вида из `KINDS` (её id — `next_id`), строки удалить/переставить — `lane::retrack`, вставка ключа — `lane::key_copied`, подсказка ключа — `lane::tip` (поля вида с умолчаниями — `Entry::fields`). Вид в редакторе — `panel::Entry` (`kinds.rs`: вид, секция панели `panel::ui::<B>`, поля `lane::fields::<B>`); `Entry::of::<B>` даёт крейт вида (`panel::KIND`), регистрация редактора их перечисляет.
- Превью (`stage.rs`, набор `dc_ui_kit::stage`): `stage::on_frame` — аннотации у указателя с боксами (порядок отрисовки, `Edit` по правилу панели) из регионов, что показывает таймлайн (`Cx::shown`); жест бокса `stage::Drag` (перенос, ручки — Shift пропорция, Alt от центра, поворот — Shift шаг 15°, привязка к данным линиям) и его `annot set`; курсор над ручкой — `stage::cursor`. Выбор, курсор и жесты — `stage::Boxes` (`boxes.rs`, `Stage`): клик выбирает верхнюю (`Answer::pick`), двойной клик по тексту — `rows::focus_text`; ЛКМ внутри выбранного вида с `OnFrame::draws` оставляет его жесту (кисть раньше в таблице редактора).

## Как тестировать

- `cargo nextest run -p dc-fx-annotations`: `tests.rs`, `arrange_tests.rs` (слои, `move`), `motion_tests.rs` (анимации), `keys_tests.rs` (ключи), `panel_tests.rs` (kittest панели над видом без своих полей: строка ключа, `--at`, «Авто-ключи», общие строки).

## Куда не лезть

- Отрисовка видов и их команды — в крейтах видов. Регистрация — `crates/ops/src/devcast.rs`. Порядок эффектов в кадре — `dc_ops::Evaluator`.
