# dc-fx-annotations (`fx/annotations`)

Общее для аннотаций: модель (время, дорожки, слои, бокс, поворот) и команды `annot add|set|move|layer|rm` (5.29). Дальше здесь же анимации входа/выхода (5.30) и кейфреймы (5.31).

## Инварианты

- Зависит только от dc-core (позже dc-render, dc-ui-kit). Виды аннотаций (`fx/text`, `shape`, `image`, `drawing`, `blur`) зависят от этого крейта, а не наоборот.
- Состояние `AnnotationsState` в `project.effects["annotations"]`: `annotations`, счётчик `ids` (`a<число>`, номера не повторяются). Список `ls annots`.
- Аннотация: `kind`, `media` + `range` в source time записи (показ `start <= t < end`), `track` 0..`TRACKS`, `rect` — бокс в долях кадра проекта до камеры (едет с камерой, решение 000), `rotation` — градусы по часовой вокруг центра бокса, ±360.
- Поля вида лежат в `body` (JSON-объект) и принадлежат крейту вида: он читает и пишет их через `Annotation::body`/`set_body`, недостающие поля — значения по умолчанию его типа. Новый вид не меняет этот крейт: имена видов (`Kind`) заданы здесь.
- Порядок отрисовки (`shown_at`): по дорожке снизу вверх, внутри дорожки по порядку в `annotations`. Перекрытие по времени разрешено везде.
- Время в аргументах — время готового видео (`TimeArg<Output>`), перевод через `TimeMap` (`span.rs`). Аннотация лежит в одной записи, не короче `MIN_DURATION` (0,1 с) на выходе.
- `move --at` сохраняет длину на выходе; смена дорожки кладёт аннотацию сверху новой дорожки. `layer up|down` проходит мимо ближайшей аннотации той же дорожки, которая на экране одновременно; `top|bottom` — к краю дорожки.
- Команда без реальных изменений возвращает пустой `Diff`; ошибка не меняет проект.

## Как тестировать

- `cargo nextest run -p dc-fx-annotations`: `tests.rs` (add/set/rm, ошибки, время через вырез, 2× и вторую запись, undo/redo, файл проекта, поля вида, `ls`), `arrange_tests.rs` (порядок слоёв, `layer`, `move`).

## Куда не лезть

- Отрисовка видов и их команды — в крейтах видов. Регистрация — `crates/cli/src/registry.rs`. Порядок эффектов в кадре — `dc_ops::Evaluator`.
