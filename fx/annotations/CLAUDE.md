# dc-fx-annotations (`fx/annotations`)

Общее для аннотаций: модель (время, дорожки, слои, бокс, поворот) и команды `annot add|set|move|paste|layer|rm` (5.29; `paste` — 7.9), анимации входа и выхода, `annot anim` (5.30), ключевые кадры, `annot key add|rm|copy` (5.31).

## Инварианты

- Зависит от dc-core и dc-render (позже dc-ui-kit). Виды аннотаций (`fx/text`, `shape`, `image`, `drawing`, `blur`) зависят от этого крейта, а не наоборот.
- Состояние `AnnotationsState` в `project.effects["annotations"]`: `annotations`, счётчик `ids` (`a<число>`, номера не повторяются). Список `ls annots`.
- Аннотация: `kind`, `media` + `range` в source time записи (показ `start <= t < end`), `track` 0..`TRACKS`, `rect` — бокс в долях кадра проекта до камеры (едет с камерой, решение 000), `rotation` — градусы по часовой вокруг центра бокса, ±360.
- Поля вида лежат в `body` (JSON-объект) и принадлежат крейту вида: он читает их через `Annotation::body`, а команда `set` вида меняет через `edit_kind` (проверка вида, затем `edit_body`), недостающие поля — значения по умолчанию его типа. Новый вид не меняет этот крейт: имена видов (`Kind`) заданы здесь.
- Порядок отрисовки (`shown_at`): по дорожке снизу вверх, внутри дорожки по порядку в `annotations`. Перекрытие по времени разрешено везде.
- `Placement::of(annotation, canvas)` — бокс в px холста до камеры, поворот, `k` (px холста на px при короткой стороне 1080, `dc_render::REFERENCE`), `opacity` и `reveal` (доля показанного: буквы печати, длина пути draw-in): из него рисуют все виды. `Placement::at(…, map, now, t)` — с анимацией кадра (`Pose`) и боксом и поворотом из ключей. Ключи меняют `Placement` и поля вида, а не код видов. Рисует аннотации `dc_ops` (`annotations.rs`): вид → слой в `Band::Annotations`.
- Анимации (`motion.rs`, выжимка §3): `enter`/`exit` — `Stage` (анимация + длительность), по умолчанию `none` и 0,3 с, в файл не пишутся, пока по умолчанию. Длительность — время выхода (решение 000): от первого показанного момента и до конца аннотации на готовом видео, ускорение не торопит, вырез не съедает. Применяется не длиннее показа, вход первым (зажим при расчёте кадра, а не в командах, поэтому вырезы и смена длины его не ломают). Выход — вход наоборот (slide_left уезжает влево, печать стирает с конца). Кривые v1: fade линейно, остальное smoothstep; pop `0.58+0.42e+0.14·sin(πe)` вокруг центра; slide 96/72 ref-px, сдвиг не масштабируется; typewriter и draw — `reveal` линейно (как фигура прорисовывается — `fx/shape`). `Animation::fits`: typewriter только у текста, draw — у фигур и рисунков. `shown_for` — время выхода от первого показанного момента (часы анимаций и кадров анимированных картинок).
- Ключи (`keys.rs`, выжимка §4): `Annotation::keys` — полный снимок `rect`, `rotation`, `body` на момент `at`. `at` — source time записи от начала аннотации (как сами границы аннотации): ключи едут с `move`, вырез и ускорение их не сдвигают (движение идёт вместе с кадрами записи, в отличие от длительностей анимаций), `set --from` оставляет их на тех же кадрах; ключ за краем после обрезки хранится и влияет у края (как DaVinci). Ключи по времени, ближе `KEY_TOLERANCE` (1 мс) — один момент. Не ключуются время, дорожка, слой, анимации. Значение: без ключей — сама аннотация; до первого ключа — первый, после последнего — последний (одно правило для всех параметров, в v1 было два); между — smoothstep, в каждом ключе остановка. Смешивание — трейт `Blend`: числа и `Rect` линейно, `Rgba` по каналам с округлением, остальное (`step`) — скачком в правом ключе; для `body` в командах — `Blend for Value` по тем же правилам (целые остаются целыми). Новый вид даёт `Blend` своему типу полей и сразу ключуется.
- Правка с ключами: `annot set --at` и `edit_body` (для команд видов, `text set --at`) пишут в ключ в этот момент, созданный снимком показанного; первый ключ позже начала приводит с собой ключ в начале (движение от исходного вида). Без `--at` поля меняются в аннотации и во всех ключах. `edit_body` переписывает все `body` целиком через тип вида, поэтому ключи смешиваются по полям. Правка, совпавшая с показанным, ключей не создаёт. `annot key add` — снимок (уже есть ключ — без изменений), `rm` последнего ключа переносит его значения в аннотацию, `copy` — только в аннотацию того же вида, ключ в целевом моменте заменяется. Время ключа в командах — внутри аннотации на выходе или её конец (`key_offset`).
- Время в аргументах — время готового видео (`TimeArg<Output>`), перевод через `TimeMap` (`span.rs`). Аннотация лежит в одной записи, не короче `MIN_DURATION` (0,1 с) на выходе.
- `move --at` сохраняет длину на выходе; смена дорожки кладёт аннотацию сверху новой дорожки. `paste --item <JSON аннотации> --at --duration [--track]` (буфер редактора, 7.9) — копия с новым id в новом времени (длина на выходе), вид, бокс, поворот, анимации, `body` и ключи (они от начала) едут с ней; дорожка по умолчанию — её, сверху. `layer up|down` проходит мимо ближайшей аннотации той же дорожки, которая на экране одновременно; `top|bottom` — к краю дорожки.
- Команда без реальных изменений возвращает пустой `Diff`; ошибка не меняет проект.

## Как тестировать

- `cargo nextest run -p dc-fx-annotations`: `tests.rs` (add/set/rm, ошибки, время через вырез, 2× и вторую запись, undo/redo, файл проекта, поля вида, `ls`), `arrange_tests.rs` (порядок слоёв, `layer`, `move`), `motion_tests.rs` (кривые в ключевых точках, время через вырез и 2×, зажим длительностей, `Placement::posed`, `annot anim` и ошибки, запись в файл), `keys_tests.rs` (smoothstep и удержание, смешивание цветов и JSON, правка с `--at`, снимок, ключи с `move`, через вырез и 2×, обрезка начала, `rm` и `copy`, ошибки, undo/redo и файл).

## Куда не лезть

- Отрисовка видов и их команды — в крейтах видов. Регистрация — `crates/ops/src/devcast.rs`. Порядок эффектов в кадре — `dc_ops::Evaluator`.
