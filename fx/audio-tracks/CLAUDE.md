# dc-fx-audio-tracks (`fx/audio-tracks`)

Эффект «Звук»: уровни дорожек записей (по умолчанию и свои у клипа), mute клипа, нормализация, шумоподавление, дополнительный звук по времени выхода. Модель и команды `audio channel|reset|mute|set|rm` (`AudioAdd` для `audio add` — не из реестра, см. ниже); сведение — `dc-audio`.

## Инварианты

- Зависит только от dc-core. Файлов не читает: `devcast audio add` (dc-cli) копирует и читает файл (`dc_audio::import_sound`), затем применяет `AudioAdd` (команда, не `Op`).
- Свои уровни клипа — `Clip::audio` (`dc_core::ClipAudio`, рядом с кропом): разрезанный клип сохраняет их в обеих половинах. По умолчанию — `settings.channels` состояния `effects["audio"]` (копируются настройками по умолчанию). Уровень дорожки — `ChannelLevels` с `Option` на каждый параметр: заданный у клипа параметр свой навсегда (даже равный умолчанию), остальные следуют умолчанию, не заданный нигде — нейтральный (100 %, 1×, без mute, нормализации и шумоподавления). Решение 000, «Звук».
- Дорожки: `system`, `mic` у записи, `audio-N` (с 1) у импортированного видео; `--clip` проверяет вид медиа. Громкость 0–100 (%), усиление 1–10 (×). Mute клипа целиком (`audio mute`) — отдельно от уровней, `audio reset` его не трогает.
- Доп. звук (`au<N>`, список `ls audio`, `Item::on_output`): `range` — время выхода (вырезы и скорость не сдвигают, играет 1×), `offset` — секунда файла в начале, дорожка 0–31, клипы одной дорожки не пересекаются; без `--track` — первая свободная на весь клип. Начало внутри видео, конец не позже конца видео (при добавлении длина по умолчанию обрезается концом видео), не короче 0,1 с, не длиннее файла от `offset`. После вырезов клип может оказаться за концом видео — он хранится, звучит только до конца.
- `sound(project)` — уровни в силе обычными данными (громкость 0–1); в вход микшера их переводит `dc_ops::sound::levels` (экспорт и воспроизведение в редакторе).

## Как тестировать

- `cargo nextest run -p dc-fx-audio-tracks`: `tests.rs` — умолчания и свои уровни клипа, mute и reset, пределы и дорожки, undo/redo и файл проекта; `clips_tests.rs` — первая свободная дорожка, обрезка концом видео, отказы, set/rm, вырез не двигает звук, `ls`.
- Сведение — `crates/audio/tests/extra.rs`; через CLI — `crates/cli/src/audio_tests.rs` (копия файла, разрезанный клип, вход микшера).

## Куда не лезть

- Декодирование, R128, шумоподавление, лимитер, микс — `dc-audio`. Таймлайн и панель звука — 7.x (`dc-app`).
