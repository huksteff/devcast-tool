# dc-ipc (`crates/ipc`)

Протокол между CLI devcast и запущенным редактором (local socket, JSON с длиной).

Пока пустой. Наполняется в задачах 1.11 (проба), 7.32 (см. docs/ROADMAP.md). Когда появится код, перепиши этот файл по шаблону `docs/templates/crate-CLAUDE.md`.

## Инварианты

- Если редактор держит проект, CLI пишет только через него
