# dc-core (`crates/core`)

Базовые типы ядра: время, id, геометрия, проект, карта времени, команды, история, эффекты.

## Инварианты

- Без IO, GPU и платформенного кода. Ни от кого в workspace не зависит.
- `SourceTime` и `OutputTime` — разные типы (маркер `Timeline`), смешать нельзя. Целые микросекунды; арифметика насыщающая.
- Эффекты привязаны к `SourceTime`. Нарезка, порядок клипов и скорость меняют только `Clip.trim/cuts/speeds`; перевод времени — только через `TimeMap`.
- Id: `Id<K: IdKind>`, вид `<префикс><число>`; `IdCounter` никогда не выдаёт номер повторно. Префикс `c` занят клипами.
- Проект меняется **только командами** через `History::apply` / `apply_batch`:
  - пачка применяется по принципу «всё или ничего»;
  - после каждой команды проверяется `Project::problems()`, нарушение = откат и ошибка;
  - undo/redo — снимки изменённых частей (клипы и/или отдельный эффект), обратных команд писать не нужно;
  - команда возвращает `Diff` (`Diff::added/removed/changed(id)`, `Diff::note`); изменила проект с пустым `Diff` = откат и ошибка.
- `IdKind` задаёт `NOUN` (род. п.), `PLURAL` (им. п. мн. ч.) и `LIST` (команда списка). Ненайденный id — `CommandError::not_found(id, существующие)`.
- Состояние эффекта лежит в `project.effects["<id>"]` как JSON; типизированно — `project.state::<E>()` / `set_state::<E>()`. Состояние, равное `Default`, из проекта удаляется.
- Настройки эффекта (не содержимое) лежат в поле `settings` его состояния (`SETTINGS_FIELD`): только это поле копируют настройки по умолчанию.
- Ошибки по-русски и говорят, что делать.

## Как тестировать

- `cargo nextest run -p dc-core`. Property-тесты: `time`, `geom` (поворот), `timemap` (непрерывность, монотонность, обратимость). Найденные proptest-случаи хранятся в `proptest-regressions/` — коммитить.
- Допуск `timemap`: на замедлении (скорость < 1) путь выход → исходник → выход может уйти на `ceil(1/скорость)` мкс — это предел разрешения, а не ошибка.

## Куда не лезть

- Сохранение и загрузка папки проекта — `dc-project`. Реестр команд и вывод для CLI — `dc-ops`.
- Конкретные эффекты и их команды — крейты `fx/*`.
