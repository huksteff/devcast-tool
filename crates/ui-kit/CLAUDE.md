# dc-ui-kit (`crates/ui-kit`)

Тёмная тема, шрифты, общие виджеты и все строки интерфейса на русском. Эталон вида — docs/design/recording-windows.html.

## Инварианты

- Токены макета — только в `tokens.rs` (цвета, отступы 4/8/12/16/24/32, радиусы 6/8/12, текст 12/13/15/20, контрол 32, HUD 48, иконка 16). Виджеты берут цвета и размеры оттуда, чисел «на глаз» нет.
- `install(ctx)` ставит шрифты и тему; его зовёт каждое окно и тестовый `testing::harness()`.
- Шрифты (решение 005) — из папки `fonts` рядом с программой (`dc_render::builtin_fonts_dir`, кладёт `cargo xtask deps`): Inter (400 и именованные семейства 500/600/700 — та же переменная гарнитура с осью `wght`), JetBrains Mono 500, запасной Noto Color Emoji. Встроенных шрифтов egui и системных нет.
- Тема одна (тёмная) для обеих тем ОС.
- Иконки (`icons/`: записи — `mod.rs`, редактора — `editor.rs`) — линии и точки по SVG макетов (поле 24 × 24), без шрифтов-значков. Цвета дорожек редактора — `Hue` (заливка и линия) в `tokens.rs`.
- Виджеты (`widgets/`) рисуют себя сами по токенам; у каждого есть доступное имя (подпись или `label`, у поля ввода — подсказка): по нему находят kittest и egui-mcp. Выпадающий список — `ComboBox` egui в нашей теме. Сетка мест `anchors` (ячейки 22 × 16 по три), плитки `tiles` (картинка рисуется снаружи), палитра `palette` (образцы 20 и свой цвет). Поле числа `Slider` (64 точки, знаков после точки — как у шага) применяет набранное по Enter или потере фокуса. Индикатор уровня `LevelBar` — доля 0..1, синий, > 65 % жёлтый, > 85 % красный.
- Строки интерфейса живут только здесь, в `strings.rs`, `strings/keys.rs` (клавиши редактора), `strings/inspector.rs` (инспектор) и `strings/captions.rs` (панель субтитров) (модули по окнам, шаблоны — функции); `tests/strings.rs` рисует каждую строку этих файлов и падает на букве, которой нет в шрифтах. У каждого виджета есть снимок egui_kittest (кроме открытого HSV egui: его меши на WARP рисуются по-разному).

## Как тестировать

- `cargo nextest run -p dc-ui-kit`. Снимки — `tests/snapshots/*.png`, после намеренной смены вида: `UPDATE_SNAPSHOTS=1`, затем открыть PNG и сравнить с макетом.
- Тесты строят окно через `testing::harness()` (фича `kittest`): наши шрифты и тема, WARP с компилятором шейдеров FXC (`dxcompiler.dll` Vulkan SDK в PATH роняет WARP).

## Куда не лезть

- Окна и их логика — dc-app. Рендер кадра — dc-render.
