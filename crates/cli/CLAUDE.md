# dc-cli (`crates/cli`)

Бинарник devcast: монтаж, анализ, рендер кадров и экспорт из командной строки.

Пока пустой. Наполняется в задачах 2.16–2.19 и далее по этапам (см. docs/ROADMAP.md). Когда появится код, перепиши этот файл по шаблону `docs/templates/crate-CLAUDE.md`.

## Инварианты

- Короткий вывод по умолчанию, --json по запросу
- Ошибка подсказывает, как исправить
- stdout — результат, stderr — ошибки
