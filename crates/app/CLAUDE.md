# dc-app (`crates/app`)

Бинарник devcast-app: HUD, окна записи, редактор, таймлайн, библиотека, настройки. Логика в библиотеке (`run`), `main.rs` только печатает ошибку.

## Инварианты

- Один экземпляр на пользователя (`instance.rs`): первый держит канал dc-ipc `devcast-app-<пользователь>`, второй запуск просит его показаться и выходит.
- Журнал (`logging.rs`): `%APPDATA%\DevCast\logs\devcast-app.*.log`, ротация раз в сутки, хранится 7 файлов, паника пишется в журнал с backtrace. `RUST_LOG` задаёт уровень.
- Дампы падений (`crash.rs`, единственный `unsafe` dc-app): первый экземпляр (после `instance::claim`) запускает копию программы с `--crash-server`; она живёт, пока открыт её stdin от родителя (конец stdin — родителя нет, даже убитого или не подключившегося), падение пишет minidump в `%APPDATA%\DevCast\crashes`; если запись дампов не запустилась — ошибка в журнале, приложение работает. Распознавание речи — отдельный процесс `devcast --captions-worker` (`recognition/`, решения владельца 2026-10-29 и 2026-10-31, решение 018): whisper.cpp не отменяется внутри процесса, а dc-app не линкует whisper и Vulkan (dc-transcribe ему запрещён правилом `xtask verify`), поэтому редактор запускает CLI из папки своего exe (`job::beside`, нет файла — ошибка «переустанови DevCast») и отменяет процесс убийством. Протокол — `dc_ops::recognition`. Запрос — JSON `Request` (папка, проект как в редакторе, с несохранённым, модель, язык, дорожки) в stdin; ответ — строки `Message` в stdout: `progress <0..1>`, затем `cues <JSON NewCue>` или `error <текст>` (паника — тоже `error`). Процесс зовёт тот же путь, что `devcast captions gen`. Сторона редактора — `job.rs`: поток `devcast-recognition` пишет запрос, читает строки, будит главное окно; `Job` при удалении убивает процесс.
- Окна рисует wgpu на устройстве `dc_render::Gpu` (`gpu.rs`): оно создаётся до eframe, eframe получает его клоны (`WgpuSetup::Existing`), своего не создаёт; `Shared::gpu` — оно же и рендерер egui для превью. Бэкенд один — `dc_render::BACKEND` (DX12 на Windows, решение 004): по умолчанию eframe брал Vulkan, и закрытие поповера роняло debug-сборку (swapchain Vulkan у NVIDIA на DXGI освобождался, пока GPU его читал).
- Перерисовка только по событию (решение 002): безусловный `request_repaint()` запрещён, анимации — `request_repaint_after`. Потоки (уровни, превью, запись, трей, горячие клавиши, второй запуск) будят только главное окно (`request_repaint_of(ROOT)`), а оно в своём проходе передаёт перерисовку показанным поповеру и настройкам (`app::show_windows`): `request_repaint_of` окна, которого нет, заставляет egui открыть пустое окно «egui window» по умолчанию. Кадр любого другого окна идёт через `app::other_window`: после клика или клавиши, или если кадр открыл или закрыл окно либо сдвинул запись, он будит главное окно (только его кадр открывает и закрывает окна).
- eframe собран с `inspection` + `accesskit`: `EGUI_INSPECTION=1` открывает порт для egui-mcp (`.mcp.json`, решение 012), без переменной инспекция выключена.
- Настройки (`settings.rs`) — один файл `%APPDATA%\DevCast\settings.json` и один `Store` на все окна (`app::Shared` за `Arc<Mutex>`): HUD и окно настроек правят одно и то же. Каждое изменение пишется сразу и атомарно (`Store::update`, без изменений — без записи); поля, которых нет в файле, берут умолчания; испорченный файл — ошибка с советом удалить его. Модель Whisper — `SpeechModel` (`fast`/`accurate`, как `--model` CLI).
- Окна кроме главного — deferred viewports (решение 002) с общим `Shared`. Окно настроек (`settings_window.rs`): открывается по центру монитора HUD (`app::on_hud_monitor`, как редактор), разделы слева, изменения сразу, без «Сохранить»; выбор fps и отсчёта — общие функции `fps`/`countdown` с HUD; строки — `settings_rows.rs` (подпись и элемент по центру строки, линия под строкой); модели Whisper (`models.rs`): «Скачана» по файлу в `dc_models::models_dir`, «Скачать» — загрузка `downloads.rs`: одна на модель на всю программу (`Shared::downloads`, `dc_models::ensure` на своём потоке с прогрессом), окно настроек и редактор, попросившие одну модель, ждут одну загрузку (один писатель `.part`); каждого ждущего она будит; закрытие последнего ждущего окна отменяет её (`.part` докачается), вернувшийся до конца отмены — продолжает её.
- HUD (`hud/`) — главное окно (решение 001). Все окна без рамки (HUD, поповеры, отсчёт, выбор области) строит `borderless::window`: без рамки и без тени (`with_has_shadow(false)`; на Windows его учитывает только исправленный egui-winit, решение 019): тень поповера ложилась на HUD в 8 px под ним и затемняла его, у HUD с тенью сверху светлая строка заголовка 1 px. HUD, поповеры и отсчёт — прозрачные окна `borderless::floating` (решение 020: swapchain `DxgiFromVisual` из `gpu.rs`, исправленный egui-winit создаёт их без битмапа перенаправления): окно = панель + поле под тень `borderless::margin` (6 по бокам, 4 сверху, 8 снизу — поле забирает клики, поэтому тень `WINDOW_SHADOW` меньше макетной), панель, рамку и тень рисует egui (`borderless::panel`). Цвет очистки eframe один на все окна и прозрачный; непрозрачные окна (настройки, редактор, выбор области) заливают себя `app::opaque`. HUD поверх всех, без кнопки на панели задач; Win32 (исключение из захвата по «Скрывать HUD», место в физических px) — `dc_capture::win::hud_window` (unsafe только там). Окно подгоняется под ширину полосы плюс поле тени. Место — на каждом мониторе отдельно (`placement.rs`, ключ — прямоугольник монитора), новый монитор — внизу по центру; сохраняется, когда окно сдвинулось и кнопки мыши отпущены. Перетаскивание — `StartDrag` с ручки.
- Поповеры HUD (`hud/popover.rs`) — одно окно (deferred viewport) за раз, панель в 8 px над панелью HUD (`popover::window_rect`, нижнее поле окна кончается у HUD), отступы панели — `Kind::padding` (выбор источника — 12/16/16 макета), исключено из захвата вместе с HUD по «Скрывать HUD» (`ViewportCommand::ContentProtected`: нет в записи, в стоп-кадре области и в превью), по размеру содержимого: содержимое раскладывается в полной высоте поповера (`MAX_HEIGHT` 620, дальше прокрутка), а не в текущей высоте окна; ширина «Звука» — под самое длинное имя устройства (300…460), длиннее — сокращение в середине; у каждого поповера свой заголовок окна (`Kind::title`); Esc или потеря фокуса закрывают, но фокус считается потерянным только после того, как окно его получило (окно, открытое из-за другой программы, например через UI Automation, Windows не активирует). Другие окна закрываются до старта записи.
- Поповеры «Звук» и «Частота кадров / отсчёт» (`hud/menus.rs`) правят тот же `Store`; клик по микрофону выбирает его, поповер остаётся. Индикаторы уровня (`meters.rs`): `LevelMeter` на источник открыт, только пока его показывают (все — пока открыт «Звук», выбранный микрофон — пока открыты настройки или идёт запись); каждый уровень будит главное окно; уровень старше 0,3 с считается тишиной.
- Выбор источника (`hud/picker.rs`): поповер 720 px, карточки 4 в ряд, экраны и не свёрнутые окна; превью снимает поток по одному (снимок GDI без жёлтой рамки, `dc_capture::win::preview_*`) и будит UI; выбор пишется в `Store` сразу, выбранное окно выходит на передний план; под экраном — разрешение и масштаб Windows (`MonitorInfo::scale`).
- Выбор области (`area/`, решение 001): окно без рамки размером с монитор на каждом мониторе (прямоугольник монитора в точках главного окна; `fullscreen` winit нельзя — DXGI не создаёт swapchain для такого окна, программа падала), фон — стоп-кадр монитора; рамка в физических px монитора (`model.rs`): стороны чётные, минимум 150, пресеты «16:9» и «1080p» (только двигается, гаснет на мониторе меньше); ручки ловятся в 18 px; Enter/«Начать запись» пишет область в источник и `last_area`, Esc/«Отмена» ничего не меняет; окно на мониторе HUD на первом кадре один раз просит `ViewportCommand::Focus` (`Screen::focus`): закрытый поповер выбора источника держал фокус, и без этого Esc/Enter не работали до клика (фокус окну переднего плана даёт исправленный winit, решение 019). Открывается карточкой «Область…» выбора источника с последней областью.
- Запись (`session.rs`, `recorder.rs`): состояния покой → отсчёт → `Launch` (окна закрываются за кадр до старта) → старт → запись → подготовка/отмена → покой. `ProjectRecording` живёт на потоке `devcast-recorder` от старта до конца; UI только шлёт `Request` и берёт `Event` (каждое будит UI), сам не ждёт. Таймер — часы рекордера (QPC минус паузы из событий). Пока висит «Отменить запись?», запись на паузе; закрытие вопроса любым способом — «Продолжить запись». Выход из программы (`on_exit`) останавливает и сохраняет запись. Отсчёт (`countdown.rs`) — панель 200 × 200 (радиус 24, фон 88 %) по центру записываемого, всегда исключено из захвата.
- Значок DevCast (`logo.rs`) рисуется кодом: трей и `with_icon` каждого окна; у окон один и тот же `Arc` (egui заново шлёт значок окну, если `Arc` другой). Трей (`tray.rs`) живёт в `App` (главный поток): действия меню и клика приходят каналом и будят UI, вид меню (`TrayView` из `Shared::tray_view`) применяется только при изменении. Левый клик — показать HUD, правый — меню.
- Глобальные горячие клавиши (`hotkeys.rs`) живут в `App` (главный поток), как трей; сочетания хранятся текстом `Ctrl+Shift+R` по физической клавише; перерегистрируются только при изменении; пока окно настроек ловит сочетание, глобальные сняты. Не зарегистрированные — `Shared::taken_hotkeys`, их показывает раздел «Горячие клавиши» (`settings_hotkeys.rs`).
- После стопа (`Event::Stopped`) открывается редактор (`editor/`) с проектом по центру монитора HUD (`HudPlacement::monitor`), HUD прячется; закрытие редактора показывает HUD. Ошибка подготовки — поповер `Kind::Failed` с папкой записи. `hud::bar_ui` — весь HUD без родного окна: им E2E (`e2e_tests.rs`, `#[ignore]`, пишет экран) ведёт запись кликами.
- Редактор (`editor/`, docs/design/editor.html): `editor_ui` — вся раскладка (шапка 44, таймлайн снизу 140 … 75 % окна, высота в `AppSettings::editor`, инспектор 340 справа, превью в центре), возвращает `Outcome` (открыть настройки, высота таймлайна) — им пользуются снимки. Проект — `Document` (`document.rs`): редактор — единственный писатель (lock `devcast-app`), открывает как CLI (`dc_project::Working`), меняет только `dc_ops::apply` с реестром `Registry::devcast()` — тот же проект, что у `devcast`. Кнопки и клавиши (`keys.rs`) только ставят `Action` (`actions.rs`); кадр выполняет их после раскладки и при изменении перестраивает дорожки (`timeline/tracks.rs`, `Tracks::of` по `TimeMap`) и кадр, ошибки — тосты (`Outcome::errors`). Изменение несохранённо до Ctrl+S (7.28): `session.json` пишет `Autosave` из кадра окна (`request_repaint_after` до срока), события истории копятся и пишутся в `history.jsonl` прямо перед ним; закрытие окна и выход (`on_exit`) дописывают (`Document::flush`). Битое состояние при открытии — тост; время ↔ x — `TimeScale`. Состояние кнопок без своей логики — `View` (у поля указана задача, которая его подключит); кнопки, которым нужна команда реестра, отключены. Оверлеи кнопок поверх нарисованного — через `new_child` (не `scope_builder`: тот сдвигает раскладку). Таймлайн (7.6, 7.7): что видно — `timeline::Viewport` в `View::timeline` (масштаб: `None` = весь проект, следует за окном; начало вида; множитель строк; перетаскивание указателя и бегунка), математика — `viewport.rs` над `Lanes` кадра; ввод — `timeline/pointer.rs`: колесо забирается до `ScrollArea` дорожек (Ctrl — масштаб вокруг мыши, Shift — строки ×0,5–3 в `AppSettings::editor.rows`, иначе время, а вертикальное — дорожки, если не помещаются). Шкала и линия указателя ставят `Transport::Scrub`/`Release` (пауза на время перетаскивания, превью — ключевые кадры `Seek::Keyframe`), неподвижная мышь ничего не просит (иначе вечная перерисовка); автопрокрутка у края — `request_repaint_after`. Указатель, ушедший из вида не перетаскиванием, листает вид (`Viewport::follow`). Главная дорожка (7.8): правка клипов — только команды fx/cut (`clip split/rm/move`, `cut`, `speed`), их собирает `editor/montage.rs` (время — секунды с шестью знаками, как `devcast`), каждый жест — один шаг истории. Выбор — `View::selection` (`selection.rs`, не в истории, `View::keep` после каждой правки выбрасывает пропавшее с дорожек); участок выхода — `View::range` (Shift+перетаскивание по шкале, `timeline/range.rs`, меню и поповер скорости — `egui::Area` под шкалой, нажатие мимо закрывает). Ряд клипов — `timeline/clips.rs`: виджеты клипов с именем клипа поверх фона ряда, плашки скорости поверх клипов (только в «Выборе»); перетаскивание — `View::drag`, место — по середине «призрака» (`clips::slot`); в «Лезвии» линия указателя не ловит мышь. Регионы эффектов (7.9): у `Region` дорожки есть `item` (`selection::Item`: зум, реплика, событие облачка, аннотация, доп. звук); выбор общий с клипами (клик, Ctrl+клик, рамка с пустого места дорожки — `timeline/regions.rs`), Delete удаляет регионы и клипы одним шагом. Перетаскивание (`View::gesture`, `timeline/gesture.rs`, место — `places.rs`, математика — `snap.rs`): группа или край (зона 8 точек, не больше трети региона), края плашек скорости; прилипание 8 точек к краям регионов всех дорожек, плашек и указателю (жёлтая линия, только с «Привязкой»), на дорожках зумов и доп. звука край упирается в соседа, минимум 0,1 с; аннотации и доп. звук меняют дорожку по строке под мышью. Отпускание — команды `editor/regions.rs` (`set --from/--to`, `annot move`, `callout set`, `audio set`, `speed`) одной пачкой, порядок шагов — от переднего края группы; отказ команды — тост, проект не меняется. Буфер (`clipboard.rs`, в окне, не системный): Ctrl+C/X — команды, которые добавят регион снова (`zoom add`, `callout add`, `annot/captions/audio paste` с JSON), Ctrl+V — у указателя с теми же смещениями и дорожками, вставленное выбирается (`Action::Paste`); Ctrl+A — все регионы выбранных видов, без выбора — все зумы. Esc — шаг назад (вопрос удаления, перетаскивание заголовка, меню → перетаскивание → участок → «Выбор»), его нет в таблице клавиш. Дорожки (7.10): строки — `Tracks::of(project, sound, View::least)`: проект знает только дорожки с объектами, пустые строки «+ Дорожка ▾»/«+ Аудиодорожка» — `Least` в окне (`Action::Rows` перестраивает строки). Заголовки — `timeline/heads.rs` (глаз, mute `audio channel`, ✕: пустая строка сразу, непустая — `Confirm` в поповере у кнопки; заголовок аннотаций тянется на другую строку — порядок слоёв), команды строк — `editor/rows.rs` (`annot rm`/`move --track` по порядку списка, `audio rm`/`set --track` снизу вверх, одним шагом; новых команд нет). «Призрак» — `timeline/ghost.rs` над пустым местом зумов, курсора, аннотаций и доп. звука, место и команды — `editor/adding.rs` (1 с, в клипе, у зумов и звука — между соседями); клик, Z, T добавляют через `Action::Paste` (добавленное выбирается), звук — окно rfd → `Action::Sound` → `dc_ops::import_sound` + `Document::apply_commands`. Tab — следующая аннотация под указателем. Клавиши редактора молчат только при фокусе в поле ввода (`text_edit_focused`), сработавшая снимает фокус egui (иначе Tab уводит фокус на кнопку). Волна звука (7.11): у региона строк «Микрофон», «Системный звук» и доп. звука есть `Wave` (`timeline/wave.rs`: источник — дорожка записи или файл, куски `Span` по сегментам карты времени клипа, уровень громкость × усиление); столбец 2 точки на сетке от нуля выхода берёт кадры исходника своего куска (вырез не рисуется, 4× — вчетверо больше звука на точку) и `Peaks::range` — детали растут с масштабом. Пики читает поток `devcast-peaks` (`editor/waves.rs`: `dc_audio::cached_peaks`, кэш в `cache/` проекта), каждый источник один раз за окно; пока их нет, строка без волны; ответ будит главное окно, оно — редактор (`Waves::take_news`), кадр берёт ответы (`receive`). Непрочитанный источник — предупреждение в журнале, строка без волны. Заглушённое бледное. Маркеры ключей (7.12, `timeline/marks.rs`): ◆ на регионах аннотаций в моменты ключей (`Region::keys`, ключ в вырезе или за обрезанным краем не виден, ключ в конце — в конце), пока `View::markers`; в «Выборе» клик выбирает `Selected::Key { id, at }` (время выхода, держится в пределах 1 мс), перетаскивание — `Gesture::Key`, прилипание `snap::point` к тем же целям, что края, внутри аннотации, отпускание — `annot key move`; Delete — `annot key rm` (ключи удаляемой аннотации уходят с ней). Инспектор (7.13, `editor/inspector/`): панель — функция над `Cx`; вкладка — `inspector::tab` (id и функция или номер задачи: вкладка серая), объект — `object.rs` (шапка, «Удалить» теми же командами, что Delete). Один выбранный объект открывает свою панель (`View::object`/`followed`), вкладка — свою. Группы `Cx::group`: свёрнутость в `AppSettings::inspector` (`панель.группа`, только отличное от умолчания; `editor_ui` берёт его и отдаёт `Outcome::groups`), ↺ — команды к `EditorWindow::defaults` (`dc_project::Defaults` пользователя, читаются при открытии). Строки — `inspector/rows.rs` через `settings_rows::labelled`; правка — одна команда: ползунок и цвет — черновик в памяти egui до отпускания мыши, поле числа — по Enter или потере фокуса. Зум (7.14): вкладка — `inspector/zoom.rs` (`zoom motion`: пресет, склейка, автозумы — под ними подсказка, что они только для `devcast record`, решение владельца 2026-10-31, тонкая настройка), выбранный зум — `zoom_region.rs` (`zoom set`: режим, масштаб, фокус в %, затем те же общие строки); «Подобрать зумы» (таймлайн и панели) — `Action::SuggestZooms` → `adding::suggested`: `dc_ops::click_zooms` (телеметрия записей) и `click_commands` одной записью `zoom add`, как `devcast zoom add --at clicks`; добавленное выбирается, пусто — тост с причиной. Курсор (7.15): вкладка — `inspector/cursor.rs` (`cursor`, `clicks`; строки эффекта клика общие с панелью клика — `click_style.rs`), «Своя картинка» серая (свои курсоры заморожены). Нажатия записей (клики и сочетания клавиш, `presses::Pressed`) читает поток `devcast-presses` (`presses.rs`) общим читателем `reader.rs` (он же у волны); точки — `Tracks::clicks` (`timeline/dots.rs`, после `Tracks::of` и при ответе потока), клик по точке — `Selected::Click(время выхода)` и панель `inspector/click.rs` (`click set --at`, ↺ — `click reset`). Облачко и клавиши (7.16): событие облачка — панель `inspector/callout.rs` («Событие» — `callout set`, текст «Вкл» — `callout style --text`; «Стиль облачка» — `callout style`, ↺ без текста). Текстовое поле — `rows::text`: черновик до Enter или клика мимо, Esc его выбрасывает; выбор другого объекта применяет набранное (`rows::flush` в конце инспектора). Плашки «Клавиши» — `Tracks::place_keys` (`timeline/shortcuts.rs`) после `Tracks::of`: места — `dc_fx_keys::Prepared::shown`, как у превью и экспорта (вырез выпадает, повтор — «×N»), бледные при выключенном показе, не выбираются; `Tracks::shortcuts` — число разных сочетаний и самое повторяемое для подзаголовка и образца плашки панели «Показ клавиш» (`Cx::tracks`). Субтитры (7.17): «Создать субтитры» (таймлайн, вкладка) — `Action::Generate` → `generation.rs` (`EditorWindow::captions`: модель из настроек каждый кадр, нет файла — сначала `Models::download` с пробуждением окна, затем процесс распознавания), ответ берёт `actions::run` (`generation::receive`) и ставит `CaptionsGen` одним шагом через `Document::apply_commands`; новости — `Generation::take_news` в `window::show`; «Остановить» — `Action::StopGenerating` (процесс убит). Вкладка — `inspector/captions.rs` (`Cx::captioning`: генерация, указатель, дорожки звука, выбранная реплика): показ, распознавание с прогрессом, список `inspector/cue.rs` (клик — `Action::ListPick`: выбор без перехода в панель реплики, указатель на начало), правка выбранной (`captions set/split/merge/rm`), «Очистить все» без вопроса (макет), стиль — `captions_style.rs`; реплика с таймлайна открывает ту же правку в `object.rs`. Аннотации (7.18): панель — `inspector/annotation.rs` (`Edit` — куда пишется правка, трейт `Section` вида: `annot_text/shape/image/drawing/blur.rs`), общие строки — `annotation_rows.rs` (строка ключа, «Вход и выход» `annot anim`, место в px кадра, поворот, время, дорожка, слой). Правило ключей — как в CLI: указатель на ключе (`same_moment`) — поля вида, бокс и поворот идут с `--at` этого ключа, иначе без `--at` (аннотация и все ключи); время, дорожка, слой и анимации — всегда без `--at`. Строки показывают значения в момент указателя. «Заменить…» картинки — `Action::Picture` → `adding::picture` (`dc_ops::import_picture`, как `devcast image set`); «Дублировать» — `clipboard::duplicate` (`annot paste` на том же месте), через `Action::Paste`. Звук (7.19): вкладка — `inspector/sound.rs` (`audio channel <дорожка>`, группа на дорожку записей `Cx::sound`, mute в заголовке — `Cx::group_with`), клип — `sound_clip.rs` (`audio mute`, `audio channel --clip`, ↺ — `audio reset`), доп. звук — `sound_extra.rs` (`audio set`; «Дублировать» — `audio paste` на `AudioState::free_track`). Участок клипа на «Микрофоне»/«Системном звуке» несёт `Region::clip`: клик выбирает клип (`regions::clip_sound`), не тянется. Кроп и формат (7.20): «Кроп и формат» панели превью и значок заголовка «Клипы» — `Action::OpenCrop` (пауза, `crop::CropDialog::open`: выбранный клип, иначе клип под указателем); диалог `editor/crop/` — `egui::Modal` (`mod.rs`), картинка и рамка (`view.rs`), математика рамки в px исходника (`geom.rs`: 8 ручек, внутри кадра, минимум `CROP_MIN`, пропорция — у фиксированного формата его, в «Свободном» с Shift своя; выбор формата вписывает рамку). Всё черновик: «Применить» — `crop` и `aspect` (только изменившиеся) одним шагом, «Отмена», ✕, Esc ничего не меняют; пока диалог открыт, клавиши редактора молчат.
- Превью (`editor/preview/`): кадр проекта в `View::playhead` рисует поток `devcast-preview` (`worker.rs`) путём `devcast frame` и экспорта (`Evaluator` раз на ревизию, телеметрия `dc_capture::project::telemetry_tracks`, `dc_encode::Sources`, `Compositor::draw`) в текстуру общего устройства — одну на размер; UI регистрирует её в egui как родную (`live.rs`, без копии и unsafe). Берётся только новейший запрос, ответы по поколениям (`fetch.rs`), последний кадр виден до нового, ошибка — текстом на кадре. Картинку диалога кропа рисует второй такой же поток на том же устройстве (`Preview::source`, `Want::source`: только видео клипа в момент, весь исходный кадр без кропа и эффектов), рисовальщик потока создаётся по первому запросу. Поток будит главное окно, оно — редактор (`Preview::take_news` в `editor::show`). Запрос — при смене ревизии (`refresh`), времени или размера рендера; «Полное» — пиксели кадра на экране, не больше выхода, «Быстрое» — половина стороны (`fit.rs`); больше области — прокрутка. Правка на превью (7.21–7.23, `editor/stage/`): выбранный один зум — его рамка поверх кадра без камеры (`Want::camera`; ответ потока несёт камеру кадра `Shown::camera`), перенос — фокус (у «За курсором» ставит «Точку»), угол — масштаб (`dc_fx_zoom::resize`); аннотации под указателем (`annot::shown`: строки таймлайна, порядок слоёв) — клик выбирает верхнюю, у выбранной рамка, 8 ручек (Shift — пропорция, Alt — от центра) и ручка поворота (Shift — 15°), правка в ключ под указателем (`inspector::Edit`). Экран ↔ px холста — `geom::Mapping` (место кадра и камера), бокс с поворотом — `geom::Boxed`; привязка `snap.rs` (6 точек, края и центры кадра — розовая `GUIDE`, других аннотаций — синяя; выключают N и Ctrl). Жест — `View::stage`; пока тянут, превью рисует черновик `Document::draft` (копия без истории), отпускание — одна команда `Action::Apply`, отказ команды, Esc (`stage::cancel`) и новый проект возвращают превью к проекту.
- Воспроизведение (`editor/playback/`, 7.5): часы `Clock` — пока проект звучит, начало плюс сыгранное устройством (`dc_audio::Line::heard`, картинка идёт за звуком), иначе `Instant` (нет звука, нет устройства, сбой — тогда тост). Звук — поток `devcast-sound` (`sound.rs`): микс экспорта (`dc_ops::sound::levels` + `dc_audio::Mixer` раз на ревизию) в линию на устройство по умолчанию; линия на каждый пуск, пауза закрывает её, на паузе поток ждёт канал. Без `start_sound` (тесты) — только `Instant`. Каждый кадр при игре `Playback::tick` ставит `View::playhead`, превью просит кадр этого момента (отстающие пропускает поток превью), `request_repaint_after(1/fps)` — только пока играет. Кнопки и клавиши ставят `Action::Transport`; шаг кадра и прыжки — `playback/seek.rs` (fps — наибольшая частота видео клипов, без probe 30; ключи — `Tracks::keys`, все ключи аннотаций на выходе). Конец проекта останавливает, пуск в конце — с начала; правка во время игры перезапускает звук с указателя.
- Клавиши редактора (7.3): таблица `keymap.rs` (`EditorKey`: id, имя, группа, умолчание) — единственный источник для обработки, справки, подсказок и настроек; `AppSettings::editor_keys` хранит только изменённые. Сочетание — `Shortcut` (`shortcut.rs`, текст `Ctrl+Shift+Z`, физическая клавиша; события буфера обмена egui-winit переводятся обратно в клавиши). `editor/keys.rs::act` — действие клавиши; `None` = функция ещё не готова (серая в справке и настройках), обработчик добавляет её задача. Пока открыта справка или поле ввода, клавиши редактора молчат. Подсказка кнопки с клавишей — `keys::hint`. Настройки правят глобальные и редакторские одним кодом (`keymap::Binding`), конфликт проверяется по обеим группам. Любое действие UI с проектом — команда из реестра dc-ops. Строки интерфейса — из dc-ui-kit.

## Как тестировать

- `cargo nextest run -p dc-app`: логика окон и снимки egui_kittest (`tests/snapshots`, тесты окон — `*_tests.rs` рядом с кодом, настройки — во временной папке); редактор — `editor/tests.rs` (проект во временной `Демо-запись.dcproj`) и `editor/editing_tests.rs` (правка = проект `devcast`, undo/redo клавишами, автосохранение); клавиши и справка — `editor/keys_tests.rs`, раздел настроек — `settings_hotkeys_tests.rs`; превью — `preview/fit.rs` и `fetch.rs` (размеры, запросы с поддельным потоком), `preview/worker_tests.rs` (на WARP кадр потока = кадр `devcast frame` фикстуры `clicks.dcproj` побайтно); воспроизведение — `playback/clock.rs`, `playback/seek.rs`, `editor/playback_tests.rs` (kittest с часами теста); таймлайн — `timeline/viewport_tests.rs` (математика вида), `timeline/ui_tests.rs` (колесо, ползунок, полоса, указатель), `timeline/clips_tests.rs` (главная дорожка: каждый жест = проект `devcast` той же команды, `editing_tests::by_cli`), `timeline/regions_tests.rs` (регионы: выбор, рамка, перетаскивание, края, буфер = проект `devcast` тех же шагов), `timeline/snap_tests.rs`, `timeline/marks_tests.rs` (маркеры: выбор, Delete, перенос с прилипанием и в пределах, скрытие = проект `devcast`), `timeline/wave_tests.rs` (столбцы волны через вырез и 4×, снимки с пиками тона), `editor/waves_tests.rs` (поток пиков с поддельным чтением, кэш), `timeline/rows_tests.rs` (дорожки: меню, ✕ с вопросом и без, слои, mute, призрак, Z/T/Tab, звук из файла; высокий таймлайн — `tests::harness_with`); инспектор — `editor/inspector/tests.rs` (панель выбранного, память групп, правки и сброс = `devcast keys …`, шаг на правку), `editor/inspector/zoom_tests.rs` (зум: правки и сброс = `devcast zoom motion/set …`, «Подобрать зумы» на копии `clicks.dcproj`), `editor/inspector/cursor_tests.rs` (точки кликов через вырез и 4×, правки = `devcast cursor/clicks/click set`), `editor/inspector/callout_tests.rs` (правки = `devcast callout set/style`, текст по Enter и при смене выбора, сброс стиля одним шагом), `editor/inspector/shortcuts_tests.rs` (плашки «Клавиш» через вырез, 4× и две записи, подзаголовок и образец), `editor/inspector/captions_tests.rs` (список, правка реплики и стиль = `devcast captions …`, шаг на правку, Esc в полях реплики ничего не применяет), `editor/inspector/annotation_tests.rs` и `annot_kinds_tests.rs` (аннотации: правки = `devcast text/shape/blur/drawing set`, `annot …`, `image set`, строка ключа, правка на ключе с `--at`, «Дублировать»), `editor/inspector/sound_tests.rs` (звук: правки = `devcast audio channel/mute/reset/set`, клик по участку «Микрофона» выбирает клип, «Дублировать» звука); кроп — `editor/crop/geom_tests.rs` (ручки, границы, пропорция, поля, доли без выхода за 0..1) и `editor/crop/tests.rs` (открытие, «Применить» = `devcast crop` + `aspect` одним шагом, отмена, перетаскивание; снимки `crop_dialog*.png`); правка на превью — `editor/stage/geom_tests.rs` (отображение с камерой, повёрнутый бокс, размер, поворот, привязка) и `editor/stage/tests.rs` (рамка зума и бокс аннотации = `devcast zoom set`/`annot set` одним шагом, черновик на превью, ключ, Esc; снимки `preview_*.png`); генерация — `editor/generation_tests.rs`, `downloads_tests.rs` (общая загрузка без сети: второй ждёт первую, ошибка всем, отмена последним, возврат) и `recognition/job_tests.rs` (поддельные процессы `cmd /C type` и PowerShell: ответ, отказ, обрыв, отмена убивает; поиск `devcast.exe` рядом; настоящий процесс — `crates/cli/tests/worker.rs`); проект тестов — `editor/test_project.rs`; замер потока превью подряд — `preview/speed_tests.rs` (`--run-ignored only playback_speed --no-capture`).
- Живой прогон: `EGUI_INSPECTION=1 cargo run -p dc-app`, затем egui-mcp (`attach`, `widget_tree`, `screenshot`). Из Claude desktop (пакет MSIX) запущенная программа получает виртуальный `AppData`, и сокет дампов падений там не работает (ошибка 10022 в журнале): запись дампов проверять, запуская через `explorer.exe <путь к exe>`.
