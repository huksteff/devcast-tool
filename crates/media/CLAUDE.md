# dc-media (`crates/media`)

Probe, индекс ключевых кадров, аппаратное декодирование, точный seek, кадры-превью.

Пока пустой. Наполняется в задачах 4.1–4.4 (см. docs/ROADMAP.md). Когда появится код, перепиши этот файл по шаблону `docs/templates/crate-CLAUDE.md`.

## Инварианты

- Seek возвращает ровно запрошенный кадр (ключевой кадр + декод вперёд)
- Память под кадры ограничена
