# dc-transcribe (`crates/transcribe`)

Модели Whisper (загрузка с проверкой хэша), распознавание со временем слов, кэш распознанного, разбиение слов на реплики.

## Инварианты

- Модели лежат в `models_dir()` = `%APPDATA%\DevCast\models`; источник и SHA-256 — в `Model` (решение 010). Файл под настоящим именем всегда проверен: качаем в `<файл>.part`, проверяем SHA-256, переименовываем; обрыв и отмена оставляют `.part` для докачки. HTTP — только ureq (блокирующий, rustls).
- Распознавание (`recognize`): whisper-rs 0.16 с бэкендом Vulkan: первая видеокарта Vulkan, без неё процессор (поток на физическое ядро: с потоком на логическое ggml ждёт на спин-барьерах и на занятом ПК в 10 раз медленнее). Не вызывать `whisper_rs::vulkan::list_devices`: без драйвера Vulkan whisper.cpp бросает исключение сквозь C, и процесс падает (при создании контекста эта ошибка ловится). Жадный поиск, `flash_attn(false)` и DTW по пресету модели. Логи whisper.cpp глушит `install_logging_hooks()`. Отмены нет: `set_abort_callback_safe` в whisper-rs 0.16 сломан (приводит данные к чужому типу, и whisper.cpp обрывает работу «failed to encode»).
- Звук для Whisper (`speech_samples`): дорожки суммируются в моно, 48 → 16 кГц через ФНЧ 7,2 кГц (63 отвода, без задержки).
- Слова (`words`): токен без пробела в начале или с закрывающей пунктуацией продолжает слово. Начало — DTW первого токена минус `DTW_LAG` 0,26 с (без DTW — `t0`), конец — начало следующего слова, не позже конца сегмента и не длиннее `MAX_WORD` 2 с. Времена только растут.
- Кэш (`cache`): `cache/<файл дорожки>.<поток>.<small|turbo>.<язык|auto>.words.json` со штампом (размер, время файла, начало дорожки); не совпал или не читается — распознаём заново.
- Реплики (`cues`, задача 4.14, выжимка captions §4): разрыв на конце предложения (русские «т.е.», «т.д.», «т.к.», «т.п.», «др.» не рвут — решение 000), на паузе ≥ 0,7 с, на тишине ≥ 1,5 с в зазоре, при длине ≥ 12 с; слова целиком внутри тишины ≥ 1,5 с выбрасываются; короткие соседи склеиваются; отступ до 80 мс без нахлёстов. `Cue.words` — номера слов во входном списке.
- Ошибки по-русски и говорят, что делать.

## Как тестировать

- Сборка требует Vulkan SDK (`VULKAN_SDK`, docs/SETUP.md). Распознавание на процессоре при собранном Vulkan: `GGML_VK_VISIBLE_DEVICES=` (пустое значение).
- `cargo nextest run -p dc-transcribe` — без сети и без моделей: загрузка через локальный сервер (`test_server.rs`), слова, реплики, кэш, понижение частоты.
- С моделями из `.deps/models` (не в CI): `cargo nextest run -p dc-transcribe --run-ignored only` — хэши моделей и распознавание `fixtures/audio/tts-ru.flac` (текст дословно, три реплики, начала фраз в пределах 0,2 с от настоящих).
- Большие загрузки из сети в тестах не делать.

## Куда не лезть

- Папка настроек — `dc_project::settings::dir()`; здесь только подпапка `models`. Чтение звука — `dc-audio`.
- Выбор модели «Точная»/«Быстрая» и строки интерфейса — настройки и `dc-ui-kit`. Команды CLI — `dc-cli` (`transcript.rs`).
