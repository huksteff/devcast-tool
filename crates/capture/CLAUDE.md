# dc-capture (`crates/capture`)

Трейт Recorder, запись сегментами с manifest, восстановление после вылета, платформенный захват (win/, позже mac/, linux/).

Пока пустой. Наполняется в задачах 3.1–3.14 (см. docs/ROADMAP.md). Когда появится код, перепиши этот файл по шаблону `docs/templates/crate-CLAUDE.md`.

## Инварианты

- Обычный ввод текста не пишется никогда, только сочетания с модификаторами
- Общая шкала времени (QPC) для видео, звука и ввода
- unsafe разрешён здесь с комментарием SAFETY
