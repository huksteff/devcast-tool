# dc-audio (`crates/audio`)

Звук проекта: декодирование и ресэмплинг, микс по карте времени, уровни, EBU R128, шумоподавление, поиск тишины, пики волны.

## Инварианты

- Исходные файлы не меняются, всё — фильтры при сведении.
- Общий формат: `RATE` 48 кГц, `CHANNELS` 2, `f32` вперемешку; позиция — номер кадра (`frame_at` из мкс). Моно — в оба канала без ослабления, больше двух каналов сводит FFmpeg.
- Дорожки клипа (`tracks`): у записи — дорожки `manifest.json` кроме видео (`system`, `mic`), только собранные файлы; у импортированного видео — его аудиопотоки `audio-1`, `audio-2`, …
- Время дорожки — время исходника: кадр `n` = метка FFmpeg потока `origin + n / RATE` с, где `origin` (`SourceTrack::origin`) — первый кадр видео этого медиа (`dc_media::Probe::origin_micros` из кэша probe). Так звук и картинка файла сохраняют сдвиг, как в плеерах; у записи все дорожки с тика 0 видео. Декодеру задаётся `pkt_timebase`, иначе edit list обрезает начало кадра, не сдвигая его время. `tracks`/`Mixer::new` берут `ProjectDir`. `TrackReader::fill` — произвольный доступ: вне потока тишина, назад или далеко вперёд — seek. После seek те же сэмплы, что при чтении подряд (тест): частота ≠ 48 кГц пересчитывается rubato `Fft` блоками на общей сетке от начала потока.
- Микс (`Mixer`) — один путь для превью и экспорта: `render(кадр, буфер)` по карте времени (`TimeMap`), дорожки каждого сегмента суммируются. Стык сегментов — кроссфейд `CROSSFADE` 10 мс по центру стыка (половины в сумме 1: стык внутри непрерывного звука не слышен). Скорость ≠ 1 — `atempo` цепочкой шагов 0,5–2 (`tempo::chain`); после прыжка `atempo` начинается заново за 0,1 с до места, поэтому сэмплы там могут отличаться от проигрывания подряд, при скорости 1 — совпадают.
- `atempo` держит время с точностью своего окна (замер 2026-10-28, `tempo_tests`): быстрее 1× — до 15 мс выхода, медленнее — до 23 мс исходника (до 90 мс выхода при 0,25×).
- Уровни (`Levels`) приходят готовыми от `fx/audio-tracks` (переводит `dc_ops::sound::levels`, один для экспорта и превью): по клипу mute и по каналу громкость 0–1, усиление 1–10, mute, нормализация, шумоподавление (`ChannelLevel::new` проверяет пределы); нет в списке — 1×. Общего уровня клипа нет.
- Доп. звук (`Levels::extra`, `ExtraClip`, задача 5.37): файл на выходе `start..end` с секунды файла `offset`, скорость 1, вырезы его не трогают; кадр 0 файла — его первый сэмпл (`file_track`: первый аудиопоток, `origin` — метка первого кадра; у mp3 FFmpeg сам срезает задержку кодера, у сырого ADTS `.aac` её нет в файле — ~23 мс тишины кодера играют, как в плеерах). Края клипа — тот же кроссфейд 10 мс, что стык; нормализация — по всему файлу. Импорт (`import_sound`): mp3, wav, aac, m4a, flac, ogg, файл декодируется целиком (длина `file_duration`, нечитаемый не копируется), копия — `dc_project::copy_in`.
- В конце микса лимитер: ни сэмпл, ни пик между сэмплами (4× как в EBU R128) не выше `CEILING` −1 dBTP. Усиление кадра — чистая функция звука вокруг (атака 5 мс, отпускание 100 мс линейно, удержание на ширину фильтра), поэтому после прыжка то же, что подряд (тест, ≤ 1e-6). Ниже потолка звук не меняется.
- Шумоподавление (`denoise`, задача 4.9): RNNoise (nnnoiseless) по каждому каналу, включается `ChannelLevel::with_denoise` и стоит первым (до скорости, громкости и нормализации; нормализация меряется по исходной дорожке). Выход RNNoise опаздывает на `LATENCY` 480 кадров — читается на столько вперёд (тест синхронности по огибающей, ±1 мс). После прыжка сеть начинает заново за `WARMUP` 0,5 с; подряд и кусками разного размера — тот же звук. Тест сохранения речи — синтезированная речь `fixtures/audio/tts-ru.flac` с подмешанным шумом.
- Тишина (`silence`): RMS блоков 50 мс по всем каналам ниже порога (от 0,5 с; порог по умолчанию — `threshold`: посередине в dB между 10-м и 97-м процентилем уровней блоков всей дорожки, цифровая тишина считается −90 dBFS, решение владельца 2026-11-03), блоки от начала диапазона; паузы у краёв диапазона остаются любой длины (их может продолжить соседний сегмент). Не по сэмплам, как `silencedetect`: шум поднятого микрофона даёт одиночные громкие сэмплы (решение 000).
- Голос (`voice`): у дорожки с голосом уровень речи выше шума хотя бы на `SPREAD_DB` 6 dB (те же два процентиля, `silence::measure`); шипение, выключенный микрофон и цифровая тишина — без голоса. Два уровня кэшируются в `cache/<файл дорожки>.<поток>.voice` (`voice::cached`).
- Волна (`peaks`): мин/макс сэмпла каждых `BASE` 256 кадров по всем каналам и уровни грубее в `FACTOR` 4 раза; `range(от, до, n)` точна до 256 кадров (целые грубые пики в середине, мелкие по краям). В `cache/<файл дорожки>.<поток>.peaks` лежит только мелкий уровень (i16, округление от нуля) с заголовком: размер и время файла, начало дорожки; не совпал или не читается — строится заново.
- Нормализация — настоящая EBU R128 (ebur128), не множитель: канал приводится к `TARGET` −16 LUFS одним множителем, найденным по всей дорожке исходника, до громкости и усиления (вырезы его не меняют). Если пики после множителя выше потолка, множитель подбирается так, чтобы −16 LUFS давала дорожка уже после лимитера (секущие, 2–4 прохода). Замеры кэширует `LoudnessCache` — держать один на сессию. Тишина не нормализуется (×1).
- Воспроизведение (`play.rs`, `output.rs`, задача 7.5): `Line` — очередь между `feed` (рендер `Mixer` на 0,1 с вперёд, `AHEAD`) и устройством (`Line::pull`: громкость 0..1, тишина при пустой очереди); она же часы: `heard(now)` — кадры, сыгранные устройством (от последнего буфера по времени его звучания, не больше отданного, не назад; тишина не считается). Одна линия на пуск, кадр 0 — кадр начала. `Output` — поток cpal на устройстве по умолчанию в 48 кГц стерео f32 (WASAPI сам переводит формат); сбой потока (не xrun) выключает линию (`Off::Failed`), проект без звука — `Mixer::is_silent`.

## Как тестировать

- `cargo nextest run -p dc-audio`. Воспроизведение: `tests/play.rs` (микс через линию в поддельное устройство, громкость, часы; колонки не звучат). Доп. звук: `tests/extra.rs` (место по выходу при вырезе, `offset`, уровни, mute, мягкий край, −16 LUFS), `src/file_tests.rs` (все форматы SCOPE с первого сэмпла, длина, отказы, импорт). Звук для тестов делает ffmpeg из `.deps` (`tests/common`, в юнит-тестах `src/test_util.rs`: `sine`, `aevalsrc`, `anoisesrc`) во временной папке; запись с речью — `fixtures/recordings/speech.devcast`. Ничего не проигрывать через колонки.

## Куда не лезть

- Модель уровней каналов клипа и дополнительного звука, команды — `fx/audio-tracks`. Видео — `dc-media`. Кодирование звука — `dc-encode`.
