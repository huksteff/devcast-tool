# dc-audio (`crates/audio`)

Звук проекта: декодирование и ресэмплинг, микс по карте времени, уровни, EBU R128; позже шумоподавление, волна, поиск тишины.

## Инварианты

- Исходные файлы не меняются, всё — фильтры при сведении.
- Общий формат: `RATE` 48 кГц, `CHANNELS` 2, `f32` вперемешку; позиция — номер кадра (`frame_at` из мкс). Моно — в оба канала без ослабления, больше двух каналов сводит FFmpeg.
- Дорожки клипа (`tracks`): у записи — дорожки `manifest.json` кроме видео (`system`, `mic`), только собранные файлы; у импортированного видео — его аудиопотоки `audio-1`, `audio-2`, …
- Время дорожки — метки FFmpeg потока (кадр `n` = `n / RATE` с). `TrackReader::fill` — произвольный доступ: вне потока тишина, назад или далеко вперёд — seek. После seek те же сэмплы, что при чтении подряд (тест): частота ≠ 48 кГц пересчитывается rubato `Fft` блоками на общей сетке от начала потока.
- Микс (`Mixer`) — один путь для превью и экспорта: `render(кадр, буфер)` по карте времени (`TimeMap`), дорожки каждого сегмента суммируются. Стык сегментов — кроссфейд `CROSSFADE` 10 мс по центру стыка (половины в сумме 1: стык внутри непрерывного звука не слышен). Скорость ≠ 1 — `atempo` цепочкой шагов 0,5–2 (`tempo::chain`); после прыжка `atempo` начинается заново за 0,1 с до места, поэтому сэмплы там могут отличаться от проигрывания подряд, при скорости 1 — совпадают.
- `atempo` держит время с точностью своего окна (замер 2026-10-28, `tempo_tests`): быстрее 1× — до 15 мс выхода, медленнее — до 23 мс исходника (до 90 мс выхода при 0,25×).
- Нормализация — настоящая EBU R128, не множитель.

## Как тестировать

- `cargo nextest run -p dc-audio`. Звук для тестов делает ffmpeg из `.deps` (`tests/common`: `sine`, `aevalsrc`, `anoisesrc`) во временной папке; запись с речью — `fixtures/recordings/speech.dcproj`. Ничего не проигрывать через колонки.

## Куда не лезть

- Модель уровней каналов клипа и дополнительные дорожки — `fx/audio-tracks` (5.37). Видео — `dc-media`. Кодирование звука — `dc-encode`.
