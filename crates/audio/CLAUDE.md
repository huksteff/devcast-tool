# dc-audio (`crates/audio`)

Декодирование и ресэмплинг, микс по карте времени, уровни, EBU R128, шумоподавление, волна, поиск тишины.

Пока пустой. Наполняется в задачах 4.5–4.11 (см. docs/ROADMAP.md). Когда появится код, перепиши этот файл по шаблону `docs/templates/crate-CLAUDE.md`.

## Инварианты

- Исходные файлы не меняются, всё — фильтры при сведении
- Нормализация — настоящая EBU R128, не множитель
