# dc-render (`crates/render`)

wgpu-компоновщик: видео, SDF-фигуры, blur/glow, текст, спрайты, кисть, motion blur, рендер без окна. Сейчас есть устройство (5.1); проходы — задачи 5.2–5.11.

## Инварианты

- Один рендер для превью, экспорта и CLI. Одно устройство `Gpu` (instance, adapter, device, queue): окно берёт его клоны, своего не создаёт.
- draw получает готовую Scene и ничего не решает сам.
- Выбор адаптера (`AdapterChoice`): `Auto` — настоящая видеокарта (HighPerformance), без неё программный адаптер (WARP / lavapipe); `Software` — только программный (эталоны CI). Нет никакого — `GpuError::NoAdapter`.
- Бэкенд один на ОС (`BACKEND`, решение 004): Windows — DX12 (и видеокарта, и WARP), macOS — Metal, Linux — Vulkan. Без переопределения через окружение. Эталоны кадров хранятся по бэкенду (`Gpu::info`, решение 012).
- Формат всех кадров и промежуточных текстур — `FORMAT` = `Rgba8Unorm` (egui показывает их без копии).
- wgpu ровно та версия, что у egui-wgpu (30): версия задана в корневом `Cargo.toml`.
- Без async-рантайма: futures wgpu ждёт `block::block_on` на текущем потоке.
- `Gpu::read` — плотный RGBA8 без выравнивания строк (`Image`), ждёт отправленную работу.

## Как тестировать

- `cargo nextest run -p dc-render`. `tests/gpu.rs`: устройство `Auto` и `Software` создаётся, проход очищает текстуру 67×5 (строки с выравниванием) в цвет, кадр сверяется побайтно. На CI без видеокарты оба теста идут на WARP.
- `--no-capture` печатает выбранный адаптер.

## Куда не лезть

- Окно, surface и egui — `dc-app`. Декодирование — `dc-media`, кодирование — `dc-encode`.
- Что рисовать — `evaluate` эффектов (`fx/*`), здесь только рисование.
