# dc-render (`crates/render`)

wgpu-компоновщик: видео, SDF-фигуры, blur/glow, текст, спрайты, кисть, motion blur, рендер без окна.

Пока пустой. Наполняется в задачах 5.1–5.11 (см. docs/ROADMAP.md). Когда появится код, перепиши этот файл по шаблону `docs/templates/crate-CLAUDE.md`.

## Инварианты

- Один рендер для превью, экспорта и CLI
- draw получает готовую Scene и ничего не решает сам
