# Значок приложения

`devcast.ico` используется EXE редактора, установщиком, ярлыками, окнами и треем. Он собран из предоставленного владельцем пака `Icons`: исходные картинки ICO 16×16, 32×32, 64×64, 128×128, 256×256 и PNG 24×24, 48×48 упакованы без перерисовки и изменения размера. Внутри ICO сохранены исходные данные изображений. Все семь размеров проверены декодером Windows.

Окна и трей используют картинку 48×48; сборка переводит RGB в RGBA с непрозрачным альфа-каналом. Во время записи трей добавляет прежнюю красную точку, пропорционально размеру значка.

В паке отсутствуют:

- PNG с прозрачным фоном: оба предоставленных PNG имеют формат RGB без альфа-канала;
- векторный исходник нового рисунка (SVG); существующий `devcast.svg` — прежний логотип страницы репозитория.
