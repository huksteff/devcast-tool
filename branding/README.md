# Значок приложения

Текущий знак из обновлённого пака владельца — жёлтая плитка со срезанными углами, чёрный видоискатель, красная точка записи и голубые/малиновые полоски. Фон за плиткой прозрачный. Файлы перенесены из корня `Icons`, `Icons/svg` и `Icons/png` без перерисовки; содержимое каталогов старых вариантов (`_Old`, `DontUse_Old`) не используется.

- `devcast.svg` — основной векторный рисунок 256×256, для размеров от 32 px; используется логотипом README. Только геометрия, без встроенного растра, шрифтов и внешних ресурсов.
- `devcast-small.svg` — упрощённый рисунок по сетке 16×16 для размеров 16/24 px, без мелких полосок и кольца.
- `png/devcast-<размер>.png` — готовые PNG 16, 24, 32, 48, 64, 128, 256, 512 и 1024 px из пака. Малые размеры используют упрощённый рисунок, остальные — основной.
- `devcast.ico` — Windows ICO со слоями PNG RGBA 16, 24, 32, 48, 64, 128 и 256 px. Используется EXE редактора, установщиком и ярлыками; окна и трей берут его слой 48×48. Во время записи трей добавляет прежнюю красную точку статуса.

## Обновление экспорта

После изменения SVG запусти `export-icons.cjs` (Node.js и пакет `sharp`): для 16/24 px он берёт упрощённый исходник, для остальных — основной. Эти инструменты нужны только для обновления ассетов: сборка Rust использует уже сохранённый ICO и не требует Node.js. При подключении готового пака используются его PNG и ICO, без повторного экспорта.

```powershell
npm install --prefix .deps/icon-export sharp@0.35.5
$env:NODE_PATH = (Resolve-Path .deps/icon-export/node_modules).Path
node branding/export-icons.cjs
```

Пересозданные PNG и ICO коммитятся вместе с SVG. Снимок двух состояний трея — `crates/app/tests/snapshots/tray_icon_states.png`.
