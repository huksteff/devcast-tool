# Значок приложения

Образ DevCast — экран, кодовые скобки и точка записи. Без текста и фоновой подложки. Рисунок утверждён владельцем и перенесён из сгенерированного концепта в редактируемые векторные контуры.

- `devcast.svg` — единый векторный исходник, используется логотипом README. Только геометрия и градиенты, без встроенного растра, шрифтов и внешних ресурсов.
- `png/devcast-<размер>.png` — PNG RGBA 16, 24, 32, 48, 64, 128, 256, 512 и 1024 px, полученные из SVG. Прозрачны и фон, и пустота внутри знака.
- `devcast.ico` — Windows ICO со слоями PNG RGBA 16, 24, 32, 48, 64, 128 и 256 px. Используется EXE редактора, установщиком и ярлыками; окна и трей берут его слой 48×48. Во время записи трей добавляет прежнюю красную точку статуса.

## Обновление экспорта

После изменения SVG запусти `export-icons.cjs` (Node.js и пакет `sharp`). Эти инструменты нужны только для обновления ассетов: сборка Rust использует уже сохранённый ICO и не требует Node.js.

```powershell
npm install --prefix .deps/icon-export sharp@0.35.5
$env:NODE_PATH = (Resolve-Path .deps/icon-export/node_modules).Path
node branding/export-icons.cjs
```

Пересозданные PNG и ICO коммитятся вместе с SVG. Снимок двух состояний трея — `crates/app/tests/snapshots/tray_icon_states.png`.
